RxJa 日本語データ書き込み

UV-K1 受信専用・日本語化ファーム RxJa の日本語データ（ja_res.bin）を、ブラウザから本体へ書き込みます。

このブラウザは Web Serial に対応していません。パソコン版の Chrome か Edge で開いてください（Firefox・Safari は非対応です）。

準備

  1. 本体に RxJa ファーム（f4hwn.rxja.bin）を書き込んでおきます（UV Studio など）。日本語データは RxJa ファームが受け取るので、純正ファームのままでは書けません。
  2. 書き込みケーブルで本体とパソコンをつなぎ、本体の電源を普通に入れます（PTT を押しながらのブートローダ起動ではありません）。
  3. UV Studio など、ほかのソフトがポートを使っていたら閉じます。
