使うだけの人や、記事・動画で紹介するだけの人は、気にしなくてかまいません。

ファームやソースコードを**配る**とき（改変したものを含む）は、Apache License 2.0 の条件として、次の 3 つを守ってください。

1. ライセンス文（[`LICENSE`](https://github.com/dosei/uvk1-japanese/blob/main/LICENSE)）を付ける
2. 著作権表示と、[`NOTICE`](https://github.com/dosei/uvk1-japanese/blob/main/NOTICE) の内容を残す
3. 自分で改変したところは、改変したことが分かるようにする

## 謝辞

RxJa は、F4HWN と、それより前から続く多くの人の仕事の上にあります。私は、そこに「送信しない」と「日本語で表示する」を足しただけです。

- **Dual Tachyon** さん — UV-K5 の最初のオープンソースファームを公開してくれました。ここから、今の UV-K5 / UV-K1 のファームの世界が始まりました。[DualTachyon/uv-k5-firmware](https://github.com/DualTachyon/uv-k5-firmware)
- **OneOfEleven** さん、**Egzumer** さん、**fagci** さん — 初期のカスタムファームを育ててくれた方々です。スペクトラム（バンドスコープ）は fagci さんの仕事がもとになっています。[egzumer/uv-k5-firmware-custom](https://github.com/egzumer/uv-k5-firmware-custom)
- **muzkr** さん、**Armel / F4HWN** さん — UV-K1 と UV-K5 V3（PY32F071）へのファームの移植です。[F4HWN Fusion（UV-K1 / UV-K5 V3 用）](https://github.com/armel/uv-k1-k5v3-firmware-custom)
- **Armel / F4HWN** さん — F4HWN Fusion の開発と、ブラウザで使えるツール [UV Studio](https://armel.github.io/uvstudio/) の公開をしてくれています。RxJa の機能のほとんどと、RxJa Tools の土台は、Armel さんの仕事です。
- **東雲フォント**を作り、保守してくれている方々 — 漢字・かな・半角カナを、小さな画面にきれいに出せるのは、このフォントのおかげです。

F4HWN の作者は、F4HWN から派生したものも、オープンソースのままにしてほしいと願っています。RxJa も、その願いにそって公開しています。ありがとうございました。

> [!NOTE]
> 謝辞に名前を挙げた方々が、RxJa を推奨したり保証したりしているわけではありません。RxJa の不具合は、F4HWN の作者ではなく、[RxJa のリポジトリ](https://github.com/dosei/uvk1-japanese/issues) へ知らせてください。
