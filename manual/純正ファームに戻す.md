# 純正ファームに戻す

このページでは、RxJa から **Quansheng の純正ファーム**、または**元の F4HWN** に戻す方法を説明します。書き込みの道具は、RxJa を入れたときと同じ [RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/) です（[UV Studio](https://armel.github.io/uvstudio/) を RxJa 用に日本語にしたものです。本家の UV Studio でも同じことができます）。

> [!CAUTION]
> **純正ファームも、元の F4HWN も、送信できます。** 送信を止めているのは RxJa だけです。
> UV-K1 / UV-K5 V3 は日本の技適を受けていません。技適のない無線機で電波を出すと、**電波法違反**になります。戻したあとは、**`PTT` を押さないでください**。受信だけにしてください（→ [[受信専用のしくみ]]）。

> [!NOTE]
> このページの内容は、ソースコード・RxJa Tools と UV Studio のプログラム・Quansheng の配布ファイルと取扱説明書で確かめたものです。**実機ではまだ試していません。** 確かめられなかったことは「未確認」と書いています。

## 手順の全体

1. チャンネルと校正データを保存しておく
2. 戻したいファームを用意する
3. DFU モード（RxJa Tools の画面では「書き込みモード」）にして、RxJa Tools で書き込む
4. 純正に戻した場合は、初期化（`ALL`）をしてチャンネルを入れ直す

## 1. 戻す前に保存しておくもの

- **チャンネル**：[[CHIRP]]（F4HWN v6.1.0 用ドライバー）で読み出して、ファイルに保存しておきます。純正に戻したあと、このファイルからチャンネルをコピーして使えます。
- **校正データ**：RxJa を入れたときに「校正データ保存」（本家 UV Studio では Dump Calibration）で保存した `calibration.dat` は、捨てずに取っておいてください（→ [[ファームの書き込み#1-校正データのバックアップ最初に必ず]]、[[UV-Studio]]）。まだ保存していなければ、戻す前にいまの RxJa で保存しておきます。RxJa Tools の「校正データ保存」で、本体を**ふつうに起動した状態**（`PTT` を押さずに電源オン）でつなぎ、「校正データを読み出す」→「calibration.dat をダウンロード」の順に押します。

> [!TIP]
> 元の F4HWN v6.1.0 は、設定の並びが RxJa と同じです。元の F4HWN に戻すだけなら、チャンネルと設定はそのまま使えます。それでも、念のため CHIRP で保存しておくと安心です。

## 2. 戻したいファームを用意する

### 純正ファーム

入手先は 2 つあります。

**A. RxJa Tools の一覧から選ぶ（おすすめ）**

RxJa Tools の「**ファーム書き込み**」の画面にある一覧「**ファームウェアを選ぶ**」のいちばん下に、**Quansheng (stock)** というグループがあります（グループ名は英語のままです）。2026 年 9 月の時点では、次の 3 つが入っていました（一覧では、うしろに大きさ（KB）も付きます）。

| 一覧の表示 | 機種 |
|---|---|
| `K1 v7.03.01` | UV-K1 / UV-K1(8) |
| `K1 v7.02.02` | UV-K1 / UV-K1(8) |
| `K5v3 v7.00.11` | UV-K5 V3 / UV-K5(8) V3 |

**自分の機種に合ったもの**を選んでください。これらのファイルは Quansheng ではなく、F4HWN のプロジェクトが置いているものです（RxJa Tools は、本家 UV Studio と同じ場所から一覧を取っています）。RxJa Tools・UV Studio でそのまま書き込める形になっています。

> [!IMPORTANT]
> 一覧の**いちばん上は「RxJa（受信専用・日本語）」のグループ**です。戻すときは、これを選ばないでください。**Quansheng (stock)**（純正）か、下の **F4HWN Fusion (stable)**（元の F4HWN）の中から選びます。一覧の下のヒントにも「F4HWN・純正は元に戻す用です」と書かれています。

**B. Quansheng の公式サイトからダウンロードする**

- UV-K1：<https://en.qsfj.com/support/downloads/8740>（「UV-K1/K1(8) CPS+Upgrade Tool+Firmware」）
- UV-K5 V3 / UV-K5(8) V3：<https://en.qsfj.com/support/downloads/3268>（UV-K5(8) のページ）の「UV-K5/ UV-K5(8) V3 CPS+Upgrade Tool+Firmware」

公式サイトのページは表示に JavaScript を使っていて、2026 年 9 月の時点ではうまく表示されないことがありました。

2026 年 6 月 8 日付けの UV-K1 用 zip には、英語版 `K1ENG_v7.03.05_publish.bin`、中国語版 `K1中文_v7.02.06_publish.bin`、設定ソフト（CPS）が入っていました。UV-K5 V3 用の zip（同じ日付）には、英語版 `K5ENG_v7.00.15_publish.bin` と中国語版 `K6中文_v7.01.12_publish.bin` が入っていました。設定ソフトは UV-K1 用と同じものです。

> [!WARNING]
> **公式サイトの `.bin` を、そのまま RxJa Tools（や UV Studio）で書き込まないでください。** 公式の `.bin` は暗号化された「パック形式」です。RxJa Tools も UV Studio も、ファイルを変換せずにそのまま書き込むので、中身がでたらめなファームになり、**起動しなくなります**（そうなっても、ブートローダーは残っているので DFU モードから書き直せます）。
>
> 公式のファイルを使いたいときは、RxJa のリポジトリにある `tools/serialtool` で、先に「ふつうの形」に戻します（Python 3.10 以降が必要。pyserial は要りません）。
>
> ```
> git clone https://github.com/dosei/uvk1-japanese.git
> python3 uvk1-japanese/tools/serialtool/cli.py decode K1ENG_v7.03.05_publish.bin
> ```
>
> `K1ENG_v7.03.05_publish.raw.bin` ができます。これを RxJa Tools の「**またはパソコン内のファイルを使う**」の「ファームウェアファイル（.bin）」で選びます。変換まではパソコンで確かめましたが、**変換したファイルを実機に書き込むことは未確認**です。迷ったら A の方法を使ってください。

> [!NOTE]
> 2026 年 9 月 28 日の時点で、公式サイトはファイル置き場の証明書の期限が切れていて、「Loading...」のまま何も出ないことがあります。そのときは A の方法を使ってください。
> 公式の設定ソフト（CPS）でファームを書き込めるかどうかは、未確認です。

### 元の F4HWN

RxJa Tools の「ファームウェアを選ぶ」の一覧の **F4HWN Fusion (stable)** から選びます（RxJa（受信専用・日本語）のグループではありません）。2026 年 10 月の時点の最新は v6.1.0 です。**元の F4HWN は送信できます**（上の注意を見てください）。

## 3. 書き込む

書き込みの手順は、RxJa を入れたときとほぼ同じです。[[ファームの書き込み]] の「2. DFU モードにする」と、そのあとの RxJa Tools で書き込む手順のとおりに進めてください。ちがうのは、選ぶファイルだけです。

- 一覧から選ぶとき：「ファームウェアを選ぶ」の一覧で、上で選んだファーム（Quansheng (stock) か F4HWN Fusion (stable) の中のもの）を選ぶ。
- 変換したファイルを使うとき：「**またはパソコン内のファイルを使う**」で `.raw.bin` を選ぶ。

選んだら「**ファームを書き込む**」を押し、本体のシリアルポートを選びます。「ファームの書き込みが完了しました 👍🏼」と出れば終わりです。本体は自動で再起動します。

> [!NOTE]
> 日本語データが続けて自動で書き込まれるのは、一覧から **RxJa** を選んだときだけです。純正や F4HWN を選んだとき、パソコン内のファイルを使ったときは、ファームを書き込んで終わりです（すでに本体にある日本語データについては、下の「戻したあとに残るもの」を見てください）。

> [!IMPORTANT]
> 純正ファームは、[[マルチブート]] のスロットに入れないでください。**ふつうの「ファーム書き込み」で書き込みます。** スロットに入れて切り替えると、起動時の選択画面が出なくなります。RxJa Tools（UV Studio も）は、純正ファームを「ファームスロット」の一覧には出しません。

書き込んだあと起動しないときは、もう一度 DFU モードにして書き直してください。それでもだめなら [[トラブルシューティング]] を見てください。

## 4. 純正に戻したあとの初期化

純正ファームと F4HWN（RxJa）では、設定やチャンネル名の置き方がちがいます。そのため、純正に戻すと設定が正しく読めず、表示や動きがおかしくなることがあります。戻したら、純正ファームで<strong>初期化（`ALL`）</strong>をしてください。

純正の取扱説明書（UV-K1 User Manual）では、初期化は **メニュー 55「RESET」** です。

- `VFO`：チャンネルは残して、ほかの設定を初期に戻す
- `ALL`：**チャンネルもふくめて**すべて初期に戻す

メニューで 55 番の RESET を開き、`ALL` を選ぶと、画面に `SURE?` と出ます。もう一度決定すると、工場出荷の状態で再起動します。メニューの番号は、ファームの版によってちがうかもしれません（未確認）。

初期化のあと、保存しておいたチャンネルを入れ直します。CHIRP では、**純正用のドライバー**で無線機から読み出し、その画面へ、保存しておいたファイルからチャンネルをコピー＆貼り付けして書き戻します。

> [!NOTE]
> 純正ファームのチャンネルは 200 個です（RxJa・F4HWN は 1024 個）。201 番目より後ろのチャンネルは入りません。

## 戻したあとに残るもの

ファームの書き込みで書き換わるのは、無線機のマイコンの中（ファーム本体）だけです。外付けのフラッシュ（校正データ・日本語データ・スロットなど）は、書き込みのときには書き換わりません。

| もの | どうなるか |
|---|---|
| 校正データ | 書き換わりません。純正でも F4HWN でも、同じ場所（外付けフラッシュの 0x010000）に置かれています。純正ファームで `calibration.dat` を書き戻せるかは未確認です。書き戻しは、RxJa か F4HWN に戻ってからにしてください |
| 日本語データ（0x122000〜0x14BFFF） | 書き込みでは消えません。元の F4HWN v6.1.0 はこの場所を使いません（ソースコードで確認）。**純正ファームが使うかどうかは未確認**です。純正ファームの中身に、この場所の番地と同じ数値がふくまれていたので、純正を使っているあいだに書き換わる可能性があります |
| マルチブートのスロット `1`〜`4`、設定の組 `CFG 1`〜`CFG 4` | 書き込みでは消えません。ただし純正ファームには起動時の選択画面がないので、使えません。純正ファームがこの場所を書き換えるかどうかも未確認です |
| チャンネル・設定 | 元の F4HWN v6.1.0 ならそのまま使えます。純正では正しく読めないので、上の「4. 純正に戻したあとの初期化」をしてください |

## RxJa にもう一度戻す

1. [[ファームの書き込み]] のとおりに、RxJa Tools の一覧の **RxJa（受信専用・日本語）** から選んで書き込みます（パソコン内の `f4hwn.rxja.bin` を使ってもかまいません）。最初の起動で `Init Main` と出たら、終わるまで電源を切らないでください。
2. 表示や動きがおかしいときは、RxJa の「初期化（Reset）」で `ALL` を行います（**チャンネルも消えます**。→ [[メニュー一覧#初期化reset]]）。純正で使っていたチャンネルは、CHIRP の純正用ドライバーで読み出したものを、F4HWN 用ドライバーの画面へコピーして書き戻せます（→ [[ファームの書き込み#別のファームから-rxja-に替える場合]]）。
3. 日本語データは、ふつうは残っています。なお、一覧から RxJa を選んで書き込んだときは、続けて日本語データも自動で書き込まれます。パソコン内のファイルで書き込んだときは自動では書き込まれないので、**表示が英語のまま、または文字化けするときだけ**、`ja_res.bin` を送り直してください（RxJa Tools の「日本語データ」の画面。→ [[日本語データの転送]]）。ファームと同じ版の `ja_res.bin` を使います。
4. 起動時の選択画面がおかしい、`STATE ERROR` と出るなどのときは、[[マルチブート#困ったとき]] を見てください。

> [!TIP]
> RxJa に戻ったかどうかは、メニューの「本体情報（SysInf）」で `UVK1-RxJa` と出るかで確かめてください（→ [[メニュー一覧#本体情報sysinfのページ]]）。**`PTT` を押して確かめるのはやめてください。** 書き込みがうまくいっておらず純正や F4HWN のままだと、電波が出てしまいます。
