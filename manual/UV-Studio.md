# UV Studio・RxJa Tools（ブラウザのツール）

[UV Studio](https://armel.github.io/uvstudio/) は、F4HWN の作者 Armel（F4HWN）さんが公開している、ブラウザだけで動くツールです。インストールもアカウントも要りません。

> [!TIP]
> **RxJa では、UV Studio を RxJa 用に改変した「[RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/)」（正式名 UVK1-RxJa Tools）をおすすめします。**
>
> - UV Studio の機能はほぼそのままで、画面は**日本語**です（最初から日本語。英語にも切り替えられます）。
> - 「ファーム書き込み」の一覧に **RxJa** があり、選ぶだけで書き込めます（Releases からファイルをダウンロードしなくてよい）。
> - 一覧から RxJa を選んで書き込むと、続けて**日本語データも自動で書き込みます**。書き直し用に「**日本語データ**」の画面もあります。
>
> 本家の UV Studio も使えますが、画面は英語で、一覧に RxJa は無く、日本語データも書き込めません。
>
> RxJa Tools は本家 UV Studio とは別物です。RxJa Tools の不具合は、Armel さんではなく [RxJa のリポジトリ](https://github.com/dosei/uvk1-japanese) へ知らせてください。

このページでは、本家 UV Studio の機能を、RxJa Tools での画面名と並べて説明します。RxJa でも、次の機能が使えます。

| 機能（UV Studio の左メニュー） | RxJa Tools の左メニュー | 内容 | 無線機の状態 | RxJa |
|---|---|---|---|---|
| **Live Viewer** | ライブビューア | 無線機の画面をパソコンに映す・パソコンから操作する | 通常起動 | ○ |
| **RF Log** | RF ログ | 受信ログをリアルタイムに見る・グラフにする | 通常起動 | ○ |
| **Flash Firmware** | ファーム書き込み | ファームを書き込む | **DFU モード** | ○（→ [[ファームの書き込み]]） |
| （なし） | 日本語データ | 日本語データ（`ja_res.bin`）を書き込む | 通常起動 | ○（RxJa Tools だけ。→ [[日本語データの転送]]） |
| （なし） | メモリーチャンネル | チャンネルの読み込み・編集・書き込み、CSV | 通常起動 | ○（RxJa Tools だけ。→ [[メモリーチャンネル]]） |
| **Firmware Slots** | ファームスロット | マルチブートのスロットにファームを入れる | 通常起動 | ○（→ [[マルチブート]]） |
| **Apps (Labs)** | アプリ（Labs） | 追加アプリを入れる | 通常起動 | ×（RxJa には追加アプリの機能がありません） |
| **Dump Calibration** | 校正データ保存 | 校正データを読み出して保存 | 通常起動 | ○ |
| **Restore Calibration** | 校正データ復元 | 校正データを書き戻す | 通常起動 | ○ |
| **Upload Logo** | ロゴ書き込み | 起動画面の絵（128×64）を書き込む | 通常起動 | ○ |
| **Download Logo** | ロゴ読み出し | 起動画面の絵を読み出す | 通常起動 | ○ |
| **Export RF Log** | RF ログ書き出し | 受信ログを CSV で保存 | 通常起動 | ○ |
| **About** | このツールについて | ツールの説明 | — | — |

本家 UV Studio の画面は英語です（英・仏・独・西・伊・蘭・波・葡・中の切り替えがありますが、日本語はありません）。RxJa Tools は日本語と英語の切り替えです。

RxJa Tools の画面では、DFU モードを「**書き込みモード**」、通常起動を「**普通に起動した状態**」（PTT を押さずに電源オン）と書いています。

## 動く環境

- パソコンのブラウザ：**Chrome / Edge / Opera / Brave / Firefox 151 以降**（Web Serial という機能を使うため）。RxJa Tools の画面の注意書きは「パソコン版の Chrome / Edge / Opera（または Firefox 151 以降）」です。
- Safari、スマホのブラウザは使えません
- データ通信できる USB-C ケーブル

> [!IMPORTANT]
> UV Studio（RxJa Tools も同じ）と CHIRP、`upload.py` は、同じシリアルポートを同時には使えません。ほかのソフトを使うときは、**Disconnect**（RxJa Tools では「切断」）するか、タブを閉じてください。

## 接続のしかた（通常起動の機能）

1. 無線機の電源を入れて、ふつうに起動させる。
2. USB-C ケーブルでつなぐ。
3. 使いたい機能を選び、**Connect**（RxJa Tools では「接続」）または各機能のボタンを押す。
4. ブラウザにポートの一覧が出るので、無線機のポートを選んで「接続」。
5. 終わったら **Disconnect**（RxJa Tools では「切断」）を押してからケーブルを抜く。

## Live Viewer（画面ミラーとリモート操作）

RxJa Tools では「ライブビューア」です。

無線機の 128×64 ドットの画面が、そのままパソコンに映ります。<strong>日本語データを入れていれば、日本語もそのまま映ります。</strong>画面の下のキーをクリックすると、無線機のキーを押したのと同じになります（長押しにも対応）。

パソコンのキーボードでも操作できます。

| パソコンのキー | 無線機のキー |
|---|---|
| Enter または M | MENU |
| Esc | EXIT |
| F1 / F2 | サイドキー 1 / 2 |
| Ctrl | F |
| 数字キー | 数字キー |
| Shift + 数字 | 数字キーの長押し |
| スペース | 画面のスクリーンショットを保存 |

> [!NOTE]
> 送信はできません（UV Studio 側も送信の操作は送らない作りで、さらに RxJa 自体が送信しません）。

この説明書の画面の説明は、Live Viewer のスクリーンショットで確かめると分かりやすいです。

## RF Log / Export RF Log（受信ログ）

RxJa Tools では「RF ログ」「RF ログ書き出し」です。

RxJa は、受信した記録（周波数、チャンネル、長さ、強さ、電池電圧）を無線機の中に残せます（→ [[受信ログ]]）。

- **RF Log**（RF ログ）：接続中に受信したものが一覧に流れます。グラフ（分析）も見られます。
- **Export RF Log**（RF ログ書き出し）：無線機に残っている記録を読み出して、`rf-log.csv` として保存します。表計算ソフトで開けます。

> [!IMPORTANT]
> 受信ログは、サイドキーのどれかに「**受信ログ（RF LOG）**」を割り当てたときだけ記録されます。割り当てていないと `RF Log is disabled in the firmware settings.`（RxJa Tools では「ファームの設定で RF ログが無効になっています。」）と出ます（→ [[受信ログ]]）。

## 校正データのバックアップと書き戻し

| | 本家 UV Studio | RxJa Tools |
|---|---|---|
| 保存する | **Dump Calibration** → **Dump Calibration Data** → **Download calibration.dat** | 「校正データ保存」→「校正データを読み出す」→「calibration.dat をダウンロード」 |
| 書き戻す | **Restore Calibration** → ファイル（512 バイトの `.dat`）を選んで **Restore Calibration Data** | 「校正データ復元」→ ファイル（512 バイトの `.dat`）を選んで「校正データを書き戻す」 |

どちらも、無線機はふつうに起動した状態でつなぎます（DFU モードではありません）。

> [!CAUTION]
> 書き戻すのは、**同じ 1 台から保存したファイルだけ**にしてください。ほかの機体のものを書き込むと、受信感度や電池表示が狂います。
> RxJa の「音量の上限（SetVol）」も、この校正データの領域に保存されています。古いファイルを書き戻すと、SetVol も保存したときの値に戻ります。

## 起動ロゴ（Upload Logo / Download Logo）

RxJa Tools では「ロゴ書き込み」「ロゴ読み出し」です。

起動画面に好きな絵（白黒 128×64）を出せます。

1. **Upload Logo**（ロゴ書き込み）で画像ファイルを選ぶ。128×64 に縮小され、明るさのしきい値で白黒に変換されます（しきい値と白黒反転は画面で調整できます）。できあがりのプレビューを確かめて書き込む（RxJa Tools のボタンは「ロゴを本体へ書き込む」）。
2. 無線機のメニューで「起動表示（POnMsg）」を **`LOGO`（ロゴ）** にする。

「スクリーンセーバー（SetSav）」の **`LOGO`（ロゴ）** と **`LOGO+`（ロゴ+、絵が流れる）** でも、この絵が使われます。スクリーンセーバーは、バックライト時間（BLTime）が `OFF` と `ON`（常時点灯）以外のときに、バックライトが消えると表示されます。

## Flash Firmware（ファームの書き込み）

RxJa Tools では「ファーム書き込み」です。**RxJa を書き込む手順は [[ファームの書き込み]] を見てください**（RxJa Tools を使う手順です）。ポイントだけ：

- 無線機は **DFU モード**（RxJa Tools の画面では「書き込みモード」）にする（電源オフ → PTT を押しながら電源オン → PTT を離す → ケーブル接続）。
- **RxJa Tools**：「ファームウェアを選ぶ」の一覧で「**RxJa（受信専用・日本語）**」の版を選び、「ファームを書き込む」。書き込みが終わると、続けて日本語データも自動で書き込みます。一覧の F4HWN・純正（Quansheng）は、元に戻す用です（F4HWN は送信できる元のファームです）。
- **本家 UV Studio**：一覧（「Official F4HWN firmware」）に RxJa はありません（一覧の F4HWN は送信できる元のファームなので選ばない）。**or load a local file** で `f4hwn.rxja.bin` を選びます。日本語データは書き込まれないので、あとで別に転送します（→ [[日本語データの転送]]）。
- ブートローダーが 7.00.07 より古い機体には書き込めません（対象外の機種）。RxJa Tools も同じです。
- 「Download CHIRP driver」（RxJa Tools では「CHIRP ドライバ v… をダウンロード」）のボタンは、F4HWN の CHIRP ドライバーをダウンロードするものです。RxJa でもそのまま使えます（→ [[CHIRP]]）。

## 日本語データ（RxJa Tools だけ）

本家 UV Studio にはない画面です。日本語データ（`ja_res.bin`）を書き込みます。一覧から RxJa を選んでファームを書き込んだときは自動で書き込むので、この画面を使うのは書き直したいときだけです。無線機は、RxJa で**ふつうに起動した状態**でつなぎます。

→ [[日本語データの転送]] を見てください。

## Firmware Slots（マルチブート）

RxJa Tools では「ファームスロット」です。一覧に RxJa もあります。スロットに書き込むのはファームだけで、日本語データは書き込まれません。

→ [[マルチブート]] を見てください。

> [!NOTE]
> RxJa Tools でのスロットへの書き込みは、実機ではまだ確かめていません（ふつうの書き込みは、作者の UV-K1 で確かめています）。
