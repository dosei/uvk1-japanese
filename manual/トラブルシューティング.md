# トラブルシューティング

「うまくいかない」「これは故障？」と思ったときに見るページです。よくある症状と、その原因・対処を、場面ごとにまとめました。詳しい説明は、表の右の列のページにあります。

> [!NOTE]
> - このページの内容は、RxJa と RxJa Tools のソースコードと、この説明書のほかのページ、元の F4HWN Wiki を読んで確かめたもので、主な動作（RxJa Tools での書き込み・日本語の表示・受信）は実機（UV-K1）でも確かめています。
> - 「未確認」と書いたものは、ソースコードから読み取っただけで、実際にそうなるかは確かめていないことです。

## まず確かめること

多くの困りごとは、次の 3 つで片づきます。

1. **いま動いているファームが RxJa か**：`M` でメニューを開き、「本体情報（SysInf）」で `M`。`UVK1-RxJa` と `v1.2.0` などが出れば RxJa です（v0.1.2 までは `RxJa`）（→ [[メニュー一覧#本体情報sysinfのページ]]）。
2. **電池が十分にあるか**：電池が少ないと、画面に `電池残量低下` と出ます。書き込みや転送の前には、必ず充電してください。
3. **ケーブルがデータ通信できるものか**：充電専用の USB-C ケーブルでは、パソコンが無線機を見つけられません。

## 書き込み・起動

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| DFU モードにしたら、LED は点いたのに画面が真っ暗 | **正常です。** UV-K1 の DFU モード（書き込み待ち。RxJa Tools の画面では「書き込みモード」）は、上の LED が点灯し、画面は消えたままです。電源を入れ直せば、ふつうの起動に戻ります | [[ファームの書き込み#2-dfu-モードにする]] |
| 書き込んだあとの最初の起動で `Init Main` と出る | 正常です。マルチブート用に、いま書き込んだファームを控えとしてコピーしています。**終わるまで電源を切らないでください** | [[ファームの書き込み#5-初回起動]] |
| 書き込んだのに、起動画面もメニューも英語 | 日本語データ（`ja_res.bin`）がまだ本体に入っていないためです。RxJa Tools の「ファーム書き込み」で一覧から RxJa を選んだときは、ファームのあと続けて自動で書き込まれます。次の「日本語表示」を見てください | [[ファームの書き込み#4-続けて日本語データを書き込む自動]]、[[日本語データの転送]] |
| 書き込みの途中でケーブルが抜けた・電池が切れた。そのあと起動しない | 多くの場合、もう一度 DFU モードにして書き込み直せば直ります（`PTT` を押したまま電源を入れる） | [[ファームの書き込み]] |
| RxJa Tools が書き込みを断る（ブートローダーの版が古い） | ブートローダーが **7.00.07 より古い**機体は、RxJa の対象外（旧型の UV-K5 など）です。「ブートローダ: …」の表示のあと、英語で `INCOMPATIBLE BOOTLOADER VERSION` と出て止まります。RxJa Tools（本家 UV Studio も同じ）の安全装置が止めています。その機体には RxJa を使えません | [[はじめに]] |
| 書き込んだら表示や動きがおかしい（純正や別のファームから替えたとき） | 前のファームと設定の使い方がちがうためです。「初期化（Reset）」で `ALL` を行ってください（**チャンネルも消えます**。先に CHIRP で保存しておく） | [[ファームの書き込み#別のファームから-rxja-に替える場合]] |
| 電源を入れると `キーを離してください` のまま進まない | 電源を入れたとき、キーか `PTT` が押されたままになっています。すべてのキーを離すと、起動が進みます | [[画面の見かた#そのほかの表示]] |
| 電源を入れると、勝手にスキャンが始まる／スペクトラムや FM ラジオが開く | スキャン中（またはスペクトラム・FM ラジオを開いたまま）に電源を切ると、次の起動で同じ状態から始まります。止めてから電源を切れば、次はふつうに起動します | [[スキャン#電源を切ったときのスキャン]] |

> [!WARNING]
> マルチブートの切り替え中（`DO NOT POWER OFF` の表示中）に電源を切ると、起動しなくなるおそれがあります。そうなったときも、DFU モードで書き込み直してください（→ [[マルチブート#起動するファームを選ぶ]]）。

## 送信

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| `PTT` を押すと `送信禁止`（または `TX DISABLE`）と出て「ピピッ」と鳴る | **正常です。** RxJa は受信専用で、電波は出ません。表示は `PTT` を離して約 2.5 秒で消えます | [[受信専用のしくみ#ptt-を押すと]] |
| メニューに送信出力（Power）やオフセットなどの項目が無い | 送信のときだけ使う 24 項目は、はじめから隠しています | [[受信専用のしくみ#メニューから隠した項目]] |
| サイドキーの機能が `N/A` と出て、押しても「ピピッ」と鳴るだけ | 送信出力・ビーム・オフセット解除などの送信用の機能は、RxJa では使えません | [[受信専用のしくみ#サイドキーに割り当てられない機能]] |
| 画面に `L1` や `+`、鍵のマークなど、送信の設定の表示が出る | CHIRP などで書き込んだ送信の設定が表示されているだけです。RxJa では使われないので、気にしなくてかまいません | [[画面の見かた]] |

> [!CAUTION]
> マルチブートで RxJa 以外のファーム（元の F4HWN など）に切り替えると、その無線機は**送信できる状態**になります。技適のない無線機から電波を出すのは電波法違反です（→ [[マルチブート]]）。

## 受信・音

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| 信号が入っているはずなのに音が出ない | 次の順に確かめてください。①本体の音量つまみ ②「音量（SetVol）」が `OFF` や小さな値になっていないか ③「スケルチ（Sql）」が高すぎないか（`F` → `UP` / `DOWN` で下げる） ④「CTCSS（RxCTCS）」「DCS（RxDCS）」が入っていないか（画面に `CT` / `DC` と出る。入っていると、そのトーンの信号にしか音が出ない） ⑤消音（ステータスバーにスピーカーに斜線のマーク）になっていないか | [[メニュー一覧]]、[[画面の見かた#ステータスバー]] |
| 本当に電波が来ていないのか確かめたい | サイドキーの「モニター」で、スケルチを開けて雑音ごと聞けます（初期化 `ALL` のあとは `SIDE1` の短押し）。画面に `MONI` と出ます | [[キー操作]] |
| 雑音がずっと鳴っている | モニターが入ったまま（画面に `MONI`）か、スケルチが `0` です。モニターは `EXIT` の長押しでも切れます。スケルチは `F` → `UP` で上げます | [[キー操作]]、[[メニュー一覧]] |
| AM（エアバンドなど）の音がきつい・ひずむ・こもる | 「受信音質（SetRxA）」を変えてみてください。AM では `シャープ`（となりの信号に強い）/ `標準`（純正ファームに近い）/ `高感度`（帯域が広く、弱い信号で聞きやすいことがある）の 3 つです。**いまの変調が AM のときに開く**と、AM の値を選べます（FM のときは FM の値、USB では変えられません）。サイドキーの「受信音質」でも順に切り替わります | [[メニュー一覧]]、[[キー操作]] |
| FM の音質を変えたい | 同じ「受信音質（SetRxA）」で、変調が FM のときに `フラット` / `クリア` / `中間` / `強め` / `最大` から選びます | [[メニュー一覧]] |
| 信号が切れたときに「ザッ」と鳴る | 「SQﾃｰﾙ消（STE）」を ON にしてください | [[メニュー一覧]] |
| 音がひずむ・小さい（FM） | 「帯域幅（W/N）」が相手と合っていないことがあります。アマチュア無線の FM やエアバンドは広帯域、業務無線・特定小電力などは狭帯域が多いです | [[メニュー一覧]] |
| 資料に載っているエアバンドの周波数（8.33 kHz 間隔）に合わせても聞こえない | 資料の数字が、周波数ではなく **8.33 kHz のチャンネル番号**のことがあります（`126.505` → 実際は `126.500` MHz など）。VFO の「ステップ（Step）」を `8.33` にして本体で数字を入れると、ファームが実際の周波数に直します。**CHIRP で入れた値はそのまま使われる**ので、実際の周波数を入れてください | [[メニュー一覧]]、[[CHIRP]] |
| 2 波受信で、A と B を同時に聞けない | 仕様です。2 波受信は A と B をすばやく切り替えて見張っているだけで、同時には聞けません（全波受信も同じで、A・B と優先CH1・2 を順に見ています） | [[メニュー一覧#受信方式rxmode]] |
| 電池の % や電圧がおかしい | ①USB-C で充電していない状態で見る ②隠しメニューの「電池種類（BatTyp）」を、使っている電池に合わせる（パーセントの計算に使います） ③テスターで測った電圧に合わせて「電池校正（BatCal）」を直す（電圧の表示に効きます。変える前の値をメモ） | [[メニュー一覧#隠しメニュー保守]] |

## スキャン

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| チャンネルスキャンで何も止まらない・始まらない | ①チャンネルモード（MR）になっているか（周波数モードでは周波数スキャンになる） ②チャンネルがスキャンリストに入っているか（`OFF` のチャンネルは飛ばされる。「CH一覧（ChList）」か、チャンネルを表示して `5` 長押しで入れる） ③「ｽｷｬﾝﾘｽﾄ（ScList）」で選んだリストにチャンネルがあるか ④スケルチが高すぎないか | [[スキャン#チャンネルスキャン]] |
| 弱い信号を取りこぼす | 「SC速度（SetScn）」が `高速` だと、信号の無いところを早く飛ばします。`標準` に戻してみてください | [[スキャン#sc速度setscn]] |
| 同じ雑音や信号で何度も止まる | 止まっているときに `M` を長押しすると、そこを除外して続けます。ずっと出ている信号には「SC再開（ScnRev）」を `時間経過` にするのも手です | [[スキャン#除外]] |
| 信号が終わっても、止まったまま動かない | 「SC再開（ScnRev）」が `再開しない` になっています。`信号断後` か `時間経過` にしてください | [[スキャン#信号で止まったあとsc再開]] |
| 除外したチャンネルが、また止まるようになった | 除外はその場だけのものなので、電源を入れ直すとすべて取り消されます。ずっと外したいチャンネルは、スキャンリストを `OFF` にしてください | [[スキャン#除外]] |
| スキャン中に `F` → `*` を押したら、スキャンが止まった | RxJa（元の F4HWN v6.1.0 も同じ）では、`F` → `*` はトーンの検索です。スキャンリストを切り替えるのは `*` 長押し、`F` → `UP` / `DOWN`、数字 2 けたです | [[スキャン#スキャン中のキー]] |
| 周波数スキャンの 1 周が長すぎる | バンド全体を回っています。探す範囲が決まっているなら、範囲スキャン（周波数モードで `5` 長押し）が便利です | [[スキャン#範囲スキャン]] |

## FM ラジオ

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| 登録してあった FM 局が全部消えた | **自動スキャン**（`F` → `*`、または `*` 長押し）をすると、48 局の登録はすべて消えて、見つかった局で登録し直されます。消えた登録は戻せないので、登録し直してください。1 局だけ探すときは `*` の短押し（手動スキャン）を使います。なお、v0.1.0 では「スキャン」を割り当てたサイドキー（初期化 `ALL` のあとは `SIDE2` の短押し）も FM ラジオの画面で自動スキャンになっていました。v0.1.1 からは手動スキャンなので、局は消えません | [[FMラジオ#自動スキャン]] |
| 自動スキャンが止まらない・同じ局ばかり登録される | v0.1.0 で FM の範囲が `76-90M` か `64-76M` のときに起きる不具合です。v0.1.1 で直したので、ファームを新しくしてください（→ [[ファームの書き込み]]）。v0.1.0 のままのときは、`*` か `EXIT` で止め、範囲を `76-108M` にしてからやり直してください | [[FMラジオ#自動スキャン]] |

| FM ラジオが途中で止まり、メイン画面になる | 仕様です。ふつうの受信（A/B の周波数）に信号が入ると、そちらが優先されます。信号が終わって 5 秒たつと、FM ラジオに戻ります | [[FMラジオ#ふつうの受信との関係]] |
| FM ラジオがつかない（エラー音が鳴る） | ふつうの受信で信号を聞いている最中や、モニター中は、FM ラジオはつきません | [[FMラジオ#つける消す]] |
| 登録した局を選ぶモード（MR）にならない | 1 局も登録していないと、MR にはなりません | [[FMラジオ#登録した局を聞くmr-モード]] |
| 局名が出ない | RDS（局名などの文字情報）には対応していません | [[FMラジオ]] |

| RxJa Tools で「ファームの設定で RF ログが無効になっています。」と出る | 同じ理由です。どれかのキーに「受信ログ」を割り当ててください | [[UV-Studio]] |
| FM ラジオを聞いていた間の記録が無い | FM ラジオを聞いている間は記録されません（ソースコードから読み取ったこと。実機では未確認） | [[受信ログ#記録されるもの]] |
| 古い記録が見つからない | 本体に残るのは 1024 件までで、古いものから消えます。画面で見られるのは新しいほうから 512 件です | [[受信ログ#記録できる数]] |
| `TX` に切り替えると、いつも `記録なし` | 正常です。RxJa は送信しないので、送信の記録はありません | [[受信ログ]] |
| 初期化しても記録が消えない | 受信ログは初期化では消えません。受信ログの画面で `M` 長押し → もう一度 `M` 長押しで消します | [[受信ログ#記録を消す]] |

## マルチブート

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| 起動時の選択画面が出ない | `M` **だけ**を押したまま電源を入れてください（`PTT` も押していると出ません）。マルチブート非対応のファーム（v5.x や純正など）に切り替えたあとは出ないので、ふつうの手順で RxJa を書き込み直します | [[マルチブート#困ったとき]] |
| `STATE ERROR`、`RESTORE REFUSED`、`SLOT NOT VALID` などと出る | 表示ごとの意味と対処をまとめてあります | [[マルチブート#困ったとき]] |
| スロットを切り替えたら、いつものチャンネルが無い | スロットごとに、別の「設定の組」（`CFG 1` など。最初は空）を使うためです。いつものチャンネルを使うときは「設定切替（SetCfg）」で `CFG M` を選びます | [[マルチブート#設定の組を切り替える設定切替]] |
| スロット 1〜4 のファームやスロットの一覧の表示の意味がわからない | 選択画面の見かたを説明しています | [[マルチブート#選択画面の見かた]] |

## 設定・チャンネル

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| 「初期化（Reset）」をしたら、チャンネルが全部消えた | `VFO` でも `ALL` でも、**チャンネルは消えます**。CHIRP で保存しておいた `.img` ファイルを開いて、無線機に書き込む（Upload）と戻せます。保存が無い場合は戻せません | [[メニュー一覧#初期化reset]]、[[CHIRP#無線機に書き込むupload]] |
| チャンネルモードでメニューの設定（ステップ、DCS、CTCSS、帯域幅、変調など）を変えたのに、チャンネルを変えたり電源を入れ直したりすると元に戻る | チャンネルモードでは、これらの変更はその場だけの一時的なものです。残したいときは「CH保存（ChSave）」で、**同じチャンネル番号に保存し直して**ください（最初からいまのチャンネル番号が選ばれています） | [[メニュー一覧#チャンネルの保存削除]] |
| 自分の設定が消えた・変わった（パソコンで書き込んだあと） | **Quansheng 純正の設定ソフト（CPS）や、CHIRP の純正用ドライバーは使わないでください。** F4HWN 独自の設定を上書きします。CHIRP では F4HWN v6.1.0 用ドライバーを使います | [[CHIRP]] |
| 「設定切替（SetCfg）」をしたら設定がおかしくなった | 別のファームや別の版の設定の組を読み込むと、並びがちがって設定がおかしくなることがあります。元の組に切り替え直すか、CHIRP の保存から戻してください | [[マルチブート#設定の組マルチコンフィグ]] |
| 「電池校正」「初期化」などのメニューが見つからない | 隠しメニューです。電源を切って、**`PTT` と `SIDE1` を押したまま電源を入れる**と出ます（電源を切るまで） | [[メニュー一覧#隠しメニュー保守]] |
| 校正データを書き戻したら、「音量（SetVol）」が変わった | 「音量（SetVol）」は校正データの領域に保存されているので、保存したときの値に戻ります。設定し直してください | [[UV-Studio#校正データのバックアップと書き戻し]] |
| 起動画面にロゴが出ない | ①RxJa Tools の「ロゴ書き込み」で、**ふつうに起動した状態で**書き込む ②「起動表示（POnMsg）」を `ロゴ` にする ③電源を入れ直す。暗すぎる・反転しているときは、RxJa Tools で「しきい値」や「白黒を反転」を変えて書き込み直します | [[UV-Studio#起動ロゴupload-logo--download-logo]] |

## 操作・画面

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| キーを押すと「ピピッ」と鳴って `F長押しで解除` と出る | キーロック中です（画面右上に鍵のマーク）。`F` の長押しで外れます。ロックは電源を入れ直しても残ります。勝手にかかるときは「自動ﾛｯｸ（KeyLck）」を見てください | [[キー操作#キーロック]] |
| キーロック中にサイドキーや `PTT` も効かない | 「ﾛｯｸ対象（SetLck）」に「機能」や「PTT」が入っています | [[キー操作#キーロック]] |
| 矢印キー（`UP` / `DOWN`）の向きが逆に感じる | 隠しメニューの「矢印操作（SetNav）」で、`左右 UV-K1` と `上下 UV-K5(8)` を切り替えられます（ファームは UV-K1 か UV-K5 かを自分では見分けられないため） | [[メニュー一覧#隠しメニュー保守]] |
| しばらくすると画面が消える | 電源が切れたのではなく**スリープ**です（受信は続けています）。キーを押すか信号が入ると戻ります。「自動OFF（SetOff）」を `OFF` にすると入らなくなります | [[画面の見かた#画面が消えたときスリープ]] |
| スリープやスクリーンセーバーから戻すとき、押したキーが効かない | 仕様です。うっかり操作しないよう、起こすときに押したキーは操作として働きません（`PTT` は例外） | [[画面の見かた#スクリーンセーバー]] |
| `*` を押したら、画面に `>123` のような表示が出た | `*` の短押しで DTMF の入力モードに入っています。送信はしないので使い道はありません。8 秒ほど待つか、`EXIT` の長押しで抜けます | [[受信専用のしくみ#そのまま残っているもの押しても意味がない]] |
| `F` → サイドキーの長押しで、機能の名前が出てきた | アクションピッカー（機能をその場で選ぶ画面）です。`EXIT` か `F` でやめられます | [[キー操作#アクションピッカー機能をその場で選ぶ]] |
| スペクトラムの画面でキーロックが効かない | 仕様です。使い終わったら `EXIT` で閉じてください | [[スペクトラム#開き方と閉じ方]] |

## パソコンとの接続

| 症状 | 原因と対処 | 詳しく |
|---|---|---|
| ポートの一覧に無線機が出てこない | ①ケーブルが**充電専用**（いちばん多い原因です） ②ブラウザが Safari やスマホのブラウザ（RxJa Tools は、パソコン版の Chrome / Edge / Opera、または Firefox 151 以降が必要） ③無線機の電源が入っていない。ケーブルを抜き差しして、増えたり消えたりする項目を探してください | [[UV-Studio#動く環境]] |
| `could not open port` などと出て、ポートを開けない | RxJa Tools・UV Studio・CHIRP・`upload.py` は、同じポートを同時に使えません。**ほかのソフトや、別のタブで開いた RxJa Tools・UV Studio を閉じて**（RxJa Tools は「切断」、UV Studio は Disconnect して）からやり直してください。なお、1 つのタブの RxJa Tools の中では、ライブビューアとほかの機能（ファーム書き込み・日本語データなど）がポートを取り合わないようになっています | [[日本語データの転送#rxja-tools-でうまくいかないとき]]、[[日本語データの転送#エラーが出たとき]] |
| CHIRP で `Radio is in programming mode` と出る | 無線機が DFU モードです。電源を入れ直して、ふつうに起動させてください。ファームの書き込み（RxJa Tools の「ファーム書き込み」）だけが DFU モード、ほかの操作（「日本語データ」、校正データ、ロゴ、CHIRP など）はすべて**ふつうの起動**で行います | [[CHIRP#うまくいかないとき]]、[[UV-Studio]] |
| RxJa Tools で `タイムアウト: 本体が見つかりません（…）` と出る（校正データの読み出しなど） | 本体のつなぎ方が、その機能と合っていません。**校正データの保存・復元は、ふつうに起動した状態**（`PTT` を押さずに電源を入れる）でつなぎます。DFU モードのままでは見つかりません。逆に、**ファームの書き込みは DFU モード**（`PTT` を押したまま電源を入れる）でつなぎます | [[ファームの書き込み#1-校正データのバックアップ最初に必ず]]、[[UV-Studio#校正データのバックアップと書き戻し]] |
| CHIRP で通信できない（タイムアウト） | ケーブルをつないだまま電源を入れると、うまく通信できないことがあります。ケーブルを抜く → 電源を入れる → ケーブルをつなぐ、の順でやり直してください | [[CHIRP#無線機から読み出すdownload]] |
| Linux で `Permission denied` | 自分を `dialout` グループに入れて、ログインし直してください | [[日本語データの転送]] |
| Windows でドライバーが要るか | Windows 10 / 11 では、専用のドライバーは要りません（標準の USB シリアルドライバーで動きます） | [[日本語データの転送]] |

## それでも解決しないとき

[GitHub の Issues](https://github.com/dosei/uvk1-japanese/issues) で知らせてください（GitHub のアカウントが必要です）。次のことを書いてもらえると、原因を調べやすくなります。

- **版**：「本体情報（SysInf）」のページ 0（`UVK1-RxJa` の版、`SLOT` と `CFG`）と、ページ 1（`BUILD` の日付とコミット）（→ [[メニュー一覧#本体情報sysinfのページ]]）
- **機種**：UV-K1 か UV-K5 V3 か
- **何をしたら、どうなったか**：押したキーや操作の順番、出た表示、期待していた動き
- **画面の写真**：RxJa Tools のライブビューアで映しているなら、スペースキーで画面のスクリーンショットを保存できます（→ [[UV-Studio]]）
- パソコンの操作で困っているとき：OS とブラウザ、使ったソフト、エラーの全文（`upload.py` なら表示されたすべての行）

> [!TIP]
> 送信関係の設定や機能は、RxJa ではわざと使えなくしています（→ [[受信専用のしくみ]]）。元の F4HWN の機能で、送信を伴わないのに動きがおかしいものは、元の F4HWN でも同じかどうかを [F4HWN の Wiki（英語）](https://github.com/armel/uv-k1-k5v3-firmware-custom/wiki) で確かめてみてください。
