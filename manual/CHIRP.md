# CHIRP でチャンネルを編集する

[CHIRP](https://chirpmyradio.com/) は、無線機のチャンネル（メモリー）をパソコンの表計算のような画面で編集できる無料ソフトです。1024 チャンネルを手で入れるのは大変なので、たくさん登録するなら CHIRP が便利です。

チャンネルだけを編集するなら、インストールのいらない RxJa Tools の [[メモリーチャンネル]] の画面も使えます。CSV は CHIRP と同じ形式なので、行き来できます。

RxJa は、設定の並び（メモリーマップ）が **F4HWN Fusion v6.1.0 とまったく同じ**です。そのため、**F4HWN v6.1.0 用の CHIRP ドライバー**がそのまま使えます。

> [!WARNING]
> - **Quansheng 純正の設定ソフト（CPS）は使わないでください。** F4HWN 独自の設定を上書きしてしまいます。
> - CHIRP に最初から入っている「Quansheng UV-K5」などのドライバーも使わないでください。並びがちがうため、まちがった場所を読み書きします。
> - 必ず**先に読み出して（Download）、そのデータをファイルに保存**してから編集してください。

## 用意するもの

| もの | 入手先 |
|---|---|
| CHIRP（next 版） | [chirpmyradio.com](https://chirpmyradio.com/projects/chirp/wiki/Download) から、自分の OS 用をダウンロード |
| F4HWN v6.1.0 用ドライバー `f4hwn.chirp.v6.1.0.py` | [F4HWN の v6.1.0 リリース](https://github.com/armel/uv-k1-k5v3-firmware-custom/releases/tag/v6.1.0) の Assets から |
| データ通信できる USB-C ケーブル | — |

> [!NOTE]
> ドライバーは RxJa のリリースには入っていません。F4HWN のリリースのものを使います。RxJa の版が上がって、もとにしている F4HWN の版が変わったときは、そのときに案内します。

## ドライバーを読み込む

CHIRP を起動するたびに、この手順が必要です。

1. CHIRP を開く。
2. メニューの **ファイル（File）** に **モジュールを読み込む（Load Module...）** が無い場合は、**ヘルプ（Help）→ 開発者モード（Developer Mode）** にチェックを入れて、CHIRP を再起動する。
3. **ファイル → モジュールを読み込む** で、`f4hwn.chirp.v6.1.0.py` を選ぶ。
4. 「実験的なドライバーです」という注意（英語）が出るので、読んで OK を押す。

これで、機種の一覧に **`UV-K1 & UV-K5 V3 (F4HWN)`** が増えます。

## 無線機から読み出す（Download）

1. **無線機の電源を先に入れる**（ふつうに起動させる。DFU モードではない）。
2. そのあとで USB-C ケーブルをつなぐ。
3. CHIRP で **無線機（Radio）→ 無線機からダウンロード（Download From Radio...）**。
4. 次のように選ぶ。
   - ポート：無線機のシリアルポート（Windows なら `COM3` など）
   - メーカー（Vendor）：**Quansheng**
   - 機種（Model）：**UV-K1 & UV-K5 V3 (F4HWN)**
5. 注意書き（英語）が出るので OK。読み出しが終わるまで待つ。
6. 読み出したら、すぐに **ファイル → 名前を付けて保存** で `.img` ファイルに保存する。これがバックアップになります。

> [!TIP]
> ケーブルをつないだまま電源を入れると、うまく通信できないことがあります（ドライバーの注意書きにもあります）。失敗したら、ケーブルを抜く → 電源を入れる → ケーブルをつなぐ、の順でやり直してください。

## 追加の項目を表示する

読み出したら、**表示（View）→ 追加フィールドを表示（Show Extra Fields）** にチェックを入れます。F4HWN 独自のチャンネル設定（スキャンリスト、コンパンダーなど）は、これを入れないと表示されません。

## 編集できるもの

### チャンネル（メモリー）

| 項目 | 内容 | RxJa での扱い |
|---|---|---|
| Frequency | 受信周波数 | そのまま使う |
| Name | チャンネル名 | **半角英数字 10 文字まで**。CHIRP では日本語は入りません（日本語の名前は [[メモリーチャンネル]] で） |
| Tone Mode / Tone / ToneSql / DTCS Code | CTCSS・DCS（トーンスクエルチ） | 受信側の設定（ToneSql、DTCS の受信コードなど）が効きます。送信トーンの設定は意味がありません |
| Mode | FM / NFM / AM / NAM / USB | NFM・NAM は「狭帯域」、FM・AM は「広帯域」の意味です |
| Duplex / Offset | 送信周波数のずれ | **意味はありません**（送信しないため）。空欄のままでかまいません |
| Power | 送信出力 | **意味はありません** |
| Skip | スキャンで飛ばす | — |
| （追加フィールド）Scanlists | どのスキャンリストに入れるか（1〜24 または ALL） | → [[スキャン]] |
| （追加フィールド）Compander | コンパンダー | 受信側（RX）の設定が効きます |
| （追加フィールド）FreqRev、PTTID、BusyCL、TXLock など | 送信関係 | **意味はありません** |

### 設定（Settings）

左側の「Settings」には、メニューの項目の多くと、F4HWN 独自の設定が並んでいます。

- **Basic Settings / Advanced Settings**：メニューにある設定。RxJa で隠している送信関係の項目も並んでいますが、変更しても送信はできません。
- **Programmable Keys**：サイドキーの割り当て（→ [[キー操作]]）。送信関係の機能を割り当てた場合、そのキーを押すと「ピピッ」と鳴って何もしません。
- **Scan Lists**：スキャンリストの名前など。
- **FM Broadcast Receiver**：FM ラジオのメモリー（→ [[FMラジオ]]）。
- **Message Line 1 / 2**：起動画面に出すメッセージ（英数字）。メニューの「起動表示（POnMsg）」が `MESSAGE` か `ALL` のときに表示されます。両方とも空欄にすると、代わりに「ようこそ」と表示されます（日本語データが入っているとき）。
- **Calibration**：**触らないでください。** 校正データです。

> [!CAUTION]
> ドライバーには「校正データも書き込む」オプションがあります（既定では書き込みません）。**ほかの無線機から読み出したデータ**を書き込むときにこれを有効にすると、その機体の校正データを上書きしてしまいます。有効にしないでください。

## 無線機に書き込む（Upload）

1. 編集が終わったら、念のためファイルに保存しておく。
2. **無線機 → 無線機にアップロード（Upload To Radio...）**。
3. 読み出したときと同じポート・メーカー・機種を選ぶ。
4. 書き込みが終わるまで、ケーブルや電源に触らない。
5. 終わると無線機が再起動します。

## 日本語データは消えない

CHIRP が読み書きするのは、チャンネルと設定の領域（外部フラッシュの先頭側）と、オプションを有効にしたときの校正データだけです。日本語データ（`ja_res.bin`、外部フラッシュの `0x122000` から）は別の場所なので、CHIRP で書き込んでも消えません。

## うまくいかないとき

| 症状 | 考えられる原因と対処 |
|---|---|
| 機種の一覧に `(F4HWN)` が無い | ドライバーを読み込んでいない。CHIRP を再起動したら読み込み直しが必要 |
| `Radio is in programming mode` と出る | 無線機が DFU モードになっている。電源を切って、ふつうに起動し直す |
| 通信できない（タイムアウト） | ①ケーブルが充電専用 ②ポートがちがう ③ケーブルをつないでから電源を入れた ④RxJa Tools・UV Studio など、ほかのソフトがポートを使っている（ブラウザのタブを閉じる） |
| 読み出した内容がでたらめ | ちがうドライバーを選んでいる。`UV-K1 & UV-K5 V3 (F4HWN)` を選び直す |
