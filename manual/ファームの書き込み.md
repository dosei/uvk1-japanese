# ファームの書き込み

このページでは、RxJa のファーム本体を無線機に書き込む手順を説明します。道具はブラウザで動く **[RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/)** を使います（インストール不要）。

RxJa Tools は、Armel F4HWN さんの [UV Studio](https://armel.github.io/uvstudio/) を RxJa 用に改めたもので、画面は日本語です。ファームの一覧に RxJa があり、ファームを書き込んだあと**日本語データも続けて自動で書き込みます**。RxJa のファイルはサイトに入っているので、Releases からダウンロードする必要もありません。

> [!WARNING]
> ファームの書き込みは自己責任です。書き込み中にケーブルを抜く・電池が切れるなどすると、無線機が起動しなくなることがあります（多くの場合は DFU モードで書き直せば直ります）。
> この手順（一覧から RxJa を選んで書き込み、続けて日本語データを自動で書き込む）は、作者の UV-K1 で確かめています。

## 手順の全体

1. 電池を充電しておく
2. **校正データをバックアップする**（通常モード）
3. 無線機を **DFU モード**にする（RxJa Tools の画面では「書き込みモード」）
4. RxJa Tools の「ファーム書き込み」で RxJa を選んで書き込む
5. 続けて日本語データが自動で書き込まれるのを待つ（PTT から手を離す）
6. 書き込めたかを確かめる

使えるブラウザは、パソコン版の Chrome・Edge・Opera（または Firefox 151 以降）です。Safari やスマートフォンでは使えません（Web Serial という機能が必要なため）。

## 1. 校正データのバックアップ（最初に必ず）

**校正データ**は、工場で 1 台ずつ調整された値（受信感度、S メーター、電池電圧などの補正）で、無線機の中の 512 バイトの領域に入っています。ファームを書き換えても通常は消えませんが、万一消えたり壊れたりすると**元に戻す方法がありません**。書き込みの前に、必ずパソコンに保存しておいてください。

1. 無線機の電源を入れて、**ふつうに起動**させる（PTT は押さない。DFU モードではありません）。
2. USB-C ケーブルでパソコンとつなぐ。
3. ブラウザで [RxJa Tools の「校正データ保存」](https://dosei.github.io/uvk1-japanese/tools/#dump-calib) を開く（左のメニューの「校正データ保存」）。
4. **校正データを読み出す** を押す → シリアルポートを選ぶ画面が出るので、無線機のポートを選んで「接続」。
5. `読み出し完了 👍🏼` と出たら **calibration.dat をダウンロード** を押して保存する。

保存した `calibration.dat` は、**機体ごとに別の名前**（例：`calibration_K1_シリアル番号.dat`）をつけて、なくさない場所に保管してください。

> [!CAUTION]
> ほかの無線機の校正データを書き戻してはいけません。受信感度や電池表示がおかしくなります。校正データは「その 1 台専用」です。

<details>
<summary>いま入っているファームが純正の場合は？</summary>

純正ファームのままでも、校正データの読み出しは使えます（ふつうに起動した状態で接続）。うまくいかない場合でも、先に RxJa を書き込んでから、書き込み直後にバックアップをとってもかまいません。ファームの書き込みでは、校正データの領域は書き換えられません。
</details>

<details>
<summary>「タイムアウト: 本体が見つかりません」と出たときは</summary>

校正データの読み出しは、**ふつうに起動した状態**でつなぎます。DFU モード（書き込みモード）のままでは読み出せません。電源を入れ直して、PTT を押さずに起動してからやり直してください。
</details>

## 2. DFU モードにする

DFU モード（ファーム書き込みモード）は、無線機の中の「ブートローダー」が動いている状態で、ここでファームを受け取ります。RxJa Tools の画面では<strong>「書き込みモード」</strong>と呼んでいます（同じものです）。

1. 無線機の**電源を切る**。
2. **PTT を押したまま**、電源を入れる。
3. PTT を離す。
4. USB-C ケーブルでパソコンとつなぐ。

UV-K1 では、**上の LED が点灯し、画面は真っ暗のまま**になります。これで DFU モードです（画面が消えているので「壊れた？」と思いがちですが、正常です）。

> [!TIP]
> DFU モードから抜けたいときは、電源を切って入れ直すだけで通常起動に戻ります。

## 3. RxJa Tools で書き込む

1. [RxJa Tools の「ファーム書き込み」](https://dosei.github.io/uvk1-japanese/tools/#flash) を開く（左のメニューの「ファーム書き込み」）。
2. **ファームウェアを選ぶ** の一覧から、**RxJa（受信専用・日本語）** のグループにある版を選ぶ（例：`v1.2.0 · 106 KB`）。
   - 同じ一覧にある **F4HWN**（Fusion など）は**送信できる**元の F4HWN、**Quansheng (stock)** は純正ファームです。これらは元に戻すとき用なので、RxJa を入れるときは選ばないでください（→ [[純正ファームに戻す]]）。
3. `ファームを読み込みました: f4hwn.rxja.bin（107460 バイト）` のように表示されることを確かめる。
4. **ファームを書き込む** を押す → シリアルポートを選ぶ画面で、無線機のポートを選ぶ。
5. ブートローダーとの接続（`ハンドシェイク完了`、`ブートローダ: 7.00.07` など）、書き込みの進み具合が表示されます。
6. `ファームの書き込みが完了しました 👍🏼` と出たら、ファームの書き込みは完了です。無線機は**自動で再起動**します。

> [!IMPORTANT]
> 書き込み中は、ケーブルを抜いたり、ブラウザのタブを閉じたり、無線機の電源を切ったりしないでください。

RxJa Tools（本家 UV Studio も同じ）には、ブートローダーの版が **7.00.07 より古い**機体（旧型 UV-K5 など、RxJa の対象外の機種）には書き込まない安全装置があります。ここで止められた場合、その機体には RxJa を使えません。

<details>
<summary>シリアルポートの選び方</summary>

ポート選択の画面に出る名前は OS やブラウザで違います。

- Windows：`USB シリアル デバイス (COM3)` のような名前
- Mac：`cu.usbmodem…`
- Linux：`ttyACM0` など

どれかわからないときは、ケーブルを抜いた状態で一覧を見て、差したあとに増えたものを選びます。何も出ないときは [[トラブルシューティング]] を見てください。
</details>

## 4. 続けて日本語データを書き込む（自動）

一覧から RxJa を選んで書き込んだ場合は、ファームの書き込みが終わると「**続けて日本語データを書き込みます（v1.2.0）**」という枠が出て、そのまま日本語データ（`ja_res.bin`）の書き込みに進みます。

1. `本体の再起動を待っています… PTT からは手を離してください。` と出ます。**PTT を押さずに**待ってください。RxJa Tools が、再起動した無線機を自動で探します。
   - 最初の起動では、画面に **`Init Main`** と出ることがあります（下の「初回起動」を参照）。終わるまで電源を切らずに待ってください。
2. 見つかると書き込みが始まり、進み具合が表示されます（1〜2 分ほどかかる見込みです）。書き込んだあと読み戻して照合します。
3. `ファームと日本語データの書き込みが完了しました 👍🏼` と出たら完了です。本体が英語表示のままなら、電源を入れ直してください。

うまく進まないとき：

| 表示・状況 | すること |
|---|---|
| `本体が RxJa で起動するのを待っています。…` と出て進まない | 本体の電源を一度切り、**PTT を押さずに**入れ直してください。それでも見つからないときは **ポートを選び直す** を押して、無線機のポートを選びます |
| `本体が見つかりませんでした。…` と出た（約 90 秒で時間切れ） | 本体をふつうに起動してから、[[日本語データの転送]] の手順で「日本語データ」の画面から書き込んでください |
| いまは日本語データを書きたくない | **日本語データは後で書く** を押すと取りやめます。あとで [[日本語データの転送]] の手順で書き込めます |

日本語データを書くまでは、RxJa は**英語表示**で動きます（壊れたわけではありません）。

> [!NOTE]
> 日本語データを自動で書き込むのは、**一覧から RxJa を選んだとき**だけです。「**またはパソコン内のファイルを使う**」で自分でビルドした `.bin` などを選んだ場合は、ファームだけを書き込みます。日本語データは [[日本語データの転送]] の手順で別に書き込んでください。

## 5. 初回起動

書き込み後の最初の起動では、次のことが起きます。

- 画面に **`Init Main`** と表示されることがあります。これは、[[マルチブート]] 用に「いま書き込んだファーム」を無線機の外部フラッシュにバックアップしているところです。**終わるまで電源を切らないでください。**
- 前のファームが純正や別の版だった場合、設定が合わずに表示がおかしいことがあります。そのときは [[メニュー一覧]] の「初期化（Reset）」で `ALL` を行ってください（チャンネルも消えます）。
- 日本語データの自動書き込みを取りやめた場合は、**起動画面やメニューは英語**のままです。[[日本語データの転送]] で書き込めば日本語になります。

## 6. 書き込めたかの確認

1. `M` を押してメニューを開き、「表示」カテゴリの「本体情報」（日本語データが入っていないときは `SysInf`）で `M` を押す。
   - **`UVK1-RxJa`** と **`v1.2.0`** が 2 行で出て、その下に小さく `F4HWN v6.1.0 BASE` と出ていれば RxJa です（→ [[メニュー一覧#本体情報sysinfのページ]]）。
   - カテゴリの画面で数字の `3` `4` と押すと、「本体情報」に直接飛べます。
2. 1 で RxJa と確かめられた**あとで**、PTT を押してみる（RxJa と出なかったときは押さないでください。前のファームのままだと電波が出ます）。「**送信禁止**」（日本語データが入っていないときは **`TX DISABLE`**）と出て、ビープが 2 回鳴れば、受信専用として動いています。

## 別のファームから RxJa に替える場合

| 今のファーム | 注意すること |
|---|---|
| 純正（Quansheng） | 純正と F4HWN では設定の使い方が一部ちがうため、表示や動きがおかしければ「初期化 → `ALL`」をしてください。チャンネルを残したい場合は、書き込む前に CHIRP の**純正用ドライバー**で読み出して保存しておき、RxJa を書き込んだあと **F4HWN 用ドライバー**で読み出した画面へ、チャンネルをコピー＆貼り付けして書き戻します（→ [[CHIRP]]） |
| F4HWN Fusion v6.1.0 | 設定の並びは同じなので、チャンネルも設定もそのまま引き継がれます。ただし送信用の設定（出力など）はメニューから見えなくなるだけで、値は残っています |
| F4HWN の古い版（v5.x など） | 念のため CHIRP でバックアップをとってから書き込み、表示がおかしければ「初期化」してください |

## RxJa を新しい版に更新する

[RxJa Tools の「ファーム書き込み」](https://dosei.github.io/uvk1-japanese/tools/#flash) で、一覧から**新しい版**を選んで、このページの手順 2〜4 をもう一度行うだけです。ファームと日本語データは組で作られていて、RxJa Tools は選んだ版の組をそのまま両方書き込みます。

ファームだけ更新して日本語データが古いままだと、新しく増えた文字が英語のまま表示されます。データの形式そのものが変わった版では、日本語表示がすべて英語に戻ります（形式の合わないデータは、安全のために使わないようにしているため）。自動書き込みを取りやめた場合や、パソコン内のファイルでファームを書いた場合はこうなるので、[[日本語データの転送]] で新しい版の日本語データを書き込んでください。

<details>
<summary>本家 UV Studio で書き込みたい場合</summary>

本家の [UV Studio](https://armel.github.io/uvstudio/) でも、ファームの書き込み自体はできます。ただし画面は英語で、一覧（Official F4HWN firmware）に RxJa は無く、日本語データも書き込めません。[Releases](https://github.com/dosei/uvk1-japanese/releases) から `f4hwn.rxja.bin` をダウンロードして **Flash Firmware** の **or load a local file** で選び、日本語データは [[日本語データの転送]] の upload.py で送ることになります。ふつうは RxJa Tools をおすすめします。
</details>
