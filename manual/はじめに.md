# はじめに

このページでは、RxJa を使い始める前に知っておいてほしいこと（対応機種、必要なもの、全体の流れ、できること・できないこと）をまとめます。

## 対応機種

RxJa は、マイコンが **PY32F071** の機種で使えます。ファームは 1 種類だけで、下の ○ の機種すべてに同じファイルを書き込みます。

| 機種 | 対応 | 備考 |
|---|---|---|
| Quansheng **UV-K1** | ○ | 主な対象。矢印キーの向きなどの既定値は UV-K1 に合わせています |
| Quansheng **UV-K1 L** | ○ | UV-K1 に大きい電池（2500 mAh）が付いたもの。本体は同じ |
| Quansheng **UV-K1(8)** / **UV-K1(8) L** | ○ | 前面が金属パネルで、電源つまみと PTT の形が違うもの。中身は UV-K1 と同じです |
| Quansheng **UV-K5 V3** | ○ | UV-K1 と同じマイコンの UV-K5。電池の下に「V3」の表示があります |
| Quansheng **UV-K5(8) V3**（中国名 UV-K6 V3） | ○ | UV-K5 V3 の外観違い。Quansheng の純正ファームも UV-K5 V3 と共通です |
| UV-K1 の透明ケース版、UV-K1s（オレンジ）など | △ | 外観だけの違いとされていますが、F4HWN でも動作の報告が見つかっていません |
| UV-K5 / K5(8) / K6 / 5R Plus の **V1**（マイコン DP32G030） | × | **書き込まないでください。** 別のファームが必要です |
| UV-K5 / K5(8) の **V2**（マイコン PY32F030） | × | **書き込まないでください。** V3 とは別の世代です |

- UV-K5 V3 と UV-K5(8) V3 は矢印キーが上下に並んでいるので、書き込んだあと隠しメニューの「矢印操作（SetNav）」を `上下 UV-K5(8)` にしてください（→ [[メニュー一覧#隠しメニュー保守]]）。
- 電池は「電池種類（BatTyp）」で K1 用・K5 用を選びます。
- UV-K1(8) の中に 8 MB のフラッシュがある、という説明を見かけることがありますが、裏付けは見つかりませんでした。UV-K1(8) も、ほかの機種と同じ 2 MB として扱います（→ [[本体の仕様]]）。

本体の仕様（受信できる周波数、画面、電池など）は [[本体の仕様]] にまとめています。

### 自分の機種を見分ける

UV-K5 系は、外から見ても V1・V2・V3 の区別がつきにくいので、次の順で確かめてください。

1. **電池の下のラベル**：UV-K5 / K5(8) で「V3」の表示がなければ、V1 か V2 です。ただし、V2 の機体に偽の「V3」ラベルを貼って売っていた例が報告されています。ラベルだけで決めないでください。
2. **純正ファームの版**：純正ファームのメニュー「VER」で **7.xx.xx** なら V3 か UV-K1 です（V1 は 2.xx / 3.xx / 4.xx、V2 は 1.xx）。
3. **ブートローダーの版**：[[ファームの書き込み]] の手順で RxJa Tools の「ファーム書き込み」を使うと、書き込みを始める前のログに「ブートローダ: 7.00.07」のようにブートローダーの版が表示されます。**7.00.07 以上**なら PY32F071 の機種です。RxJa Tools は、これより古いブートローダーの機体には書き込みません（本家 UV Studio から受け継いだしくみです）。これがいちばん確かな確認で、しかも書き込む前の安全装置になっています。

USB-C の端子があっても V3 とは限りません（V1 の UV-K5(8) にも USB-C があります）。

## 用意するもの

| もの | 用途 | 注意 |
|---|---|---|
| 無線機（UV-K1 系 / UV-K5 V3 系。上の「対応機種」を参照） | — | 電池を充電しておく。書き込み中に電池が切れると危険です |
| **データ通信できる** USB-C ケーブル | パソコンとの接続 | 充電専用ケーブルでは認識しません。つながらないときはまずケーブルを疑ってください |
| パソコン | 書き込み・日本語データの転送 | Windows / Mac / Linux のどれでも可 |
| ブラウザ（パソコン版の Chrome / Edge / Opera、または Firefox 151 以降） | [RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/) でファームと日本語データを書き込む | Web Serial に対応したブラウザが必要。Safari とスマホは不可 |

RxJa のファイル（ファーム本体と日本語データ）は、RxJa Tools に同梱されています。RxJa Tools を使うなら、**ファイルをダウンロードする必要はありません**。Python や `upload.py` も、ふつうは要りません。

### RxJa Tools について

[RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/)（正式名 UVK1-RxJa Tools）は、ブラウザで動く書き込みツールです（インストール不要）。Armel F4HWN さんの UV Studio を RxJa 用に作り変えたもので、画面は日本語です。

- 「ファーム書き込み」の一覧から RxJa を選ぶと、ファームを書き込んだあと、続けて**日本語データも自動で書き込みます**。
- 校正データの保存・復元、ライブビューア（画面ミラー）、ロゴの書き込みなど、UV Studio の機能もほぼそのまま使えます（→ [[UV-Studio]]）。
- 本家の [UV Studio](https://armel.github.io/uvstudio/) でも書き込めますが、画面が英語で、一覧に RxJa が無く、日本語データの自動書き込みもありません。RxJa には RxJa Tools をおすすめします。
- RxJa Tools は本家 UV Studio とは別物です。不具合は本家ではなく、[RxJa のリポジトリ](https://github.com/dosei/uvk1-japanese) へお知らせください。

<details>
<summary>ファイルを自分でダウンロードして書き込みたいとき（別の方法）</summary>

RxJa Tools の一覧を使わずに書き込みたいときは、[Releases](https://github.com/dosei/uvk1-japanese/releases) の最新版（いまは `rxja-v1.2.0`）から、次のファイルをダウンロードします。

| ファイル | 中身 | 送り先 |
|---|---|---|
| `f4hwn.rxja.bin` | ファーム本体（約 105 KB） | 無線機のマイコン（RxJa Tools の「またはパソコン内のファイルを使う」や、本家 UV Studio で書き込む） |
| `ja_res.bin` | 日本語フォントと訳（約 138 KB） | 無線機の SPI フラッシュ（RxJa Tools の「日本語データ」の画面で「ファイルを選ぶ」、または `upload.py` で転送） |
| `SHA256SUMS` | 上の 2 つのチェックサム | 確認用（任意） |

- パソコン内のファイルでファームを書き込んだときは、**日本語データは自動では書き込まれません**。あとで [[日本語データの転送]] をしてください。
- Python で転送したいときは、転送用のスクリプト [`upload.py`](https://github.com/dosei/uvk1-japanese/blob/main/tools/ja/upload.py) も必要です（リンク先で「Download raw file」ボタンを押すと保存できます）。Python 3 と pyserial の入れ方は [[日本語データの転送]] で説明します。
</details>

<details>
<summary>チェックサムの確かめ方（任意・ファイルをダウンロードした人向け）</summary>

ダウンロードしたファイルが壊れていないかを確かめたいときは、3 つのファイルを同じフォルダーに置いて、次のコマンドを実行します。

- Windows（PowerShell）：`Get-FileHash f4hwn.rxja.bin, ja_res.bin -Algorithm SHA256`（表示された値を `SHA256SUMS` の中身と見比べる）
- Mac：`shasum -a 256 -c SHA256SUMS`
- Linux：`sha256sum -c SHA256SUMS`

`OK` と出れば問題ありません。
</details>

## 全体の流れ

どの作業も [RxJa Tools](https://dosei.github.io/uvk1-japanese/tools/) で行います。

```
① 校正データを保存する（RxJa Tools「校正データ保存」・通常モード）
      ↓
② ファームを書き込む（RxJa Tools「ファーム書き込み」・DFU モード）… 一覧から RxJa を選ぶ
      ↓ 続けて自動で
③ 日本語データが書き込まれる（PTT から手を離して待つ）
      ↓
④ 必要なら RxJa Tools の「メモリーチャンネル」か CHIRP でチャンネルを書き込む
```

- 「通常モード」は、PTT を押さずに電源を入れて、ふつうに起動した状態です。「DFU モード」は、PTT を押しながら電源を入れた状態です（RxJa Tools の画面では「**書き込みモード**」と書いてあります）。
- ①〜③は [[ファームの書き込み]]、④は [[メモリーチャンネル]] と [[CHIRP]] で説明します。
- ③は②のあとに自動で始まります。本体が再起動するまで、PTT からは手を離して待ってください。日本語データの書き込みには 1〜2 分ほどかかる見込みです。
- ③を「日本語データは後で書く」で取りやめたときや、うまくいかなかったとき、書き直したいときは、[[日本語データの転送]] を見てください（RxJa Tools の「日本語データ」の画面で書き込めます）。
- ③をしないと、**ファームは動きますが表示は英語のまま**です（元の F4HWN と同じ英語表示になります）。壊れたわけではありません。書き込みが終わっても英語表示のままなら、本体の電源を入れ直してください。
- 日本語データは一度書けば残ります。ファームを書き直しても、日本語データは消えません。

> [!NOTE]
> RxJa Tools での書き込み（日本語データの自動書き込みを含む）と、RxJa の日本語の表示・受信は、作者の UV-K1 で確かめています。それでも、書き込みは自己責任でお願いします。

## RxJa でできること

元の F4HWN Fusion v6.1.0 の受信機能は、ほぼそのまま使えます。

- 18MHz〜1300MHz の広い範囲の受信（FM / AM / USB）※端のほうは感度が落ちます。実際に聞ける範囲は機体によります
- 2 波同時待ち受け（デュアルワッチ）、A・B と優先チャンネル 2 つを順に見張る**全波受信**（v1.2.0 から） → [[メニュー一覧#受信方式rxmode]]
- メモリーチャンネル 1024 個、名前付き（日本語も可。全角 5 文字・半角 10 文字まで。v1.1.0 から）
- スキャンリスト 24 本＋全チャンネル＋選んだリストだけの**混合**（v1.2.0 から）、優先チャンネル 2 つ、範囲スキャン、除外 → [[スキャン]]
- バンドスコープ（スペクトラム） → [[スペクトラム]]
- FM ラジオ（76〜108MHz、48 局メモリー） → [[FMラジオ]]
- 受信ログ（いつ・どの周波数を・どのくらいの強さで受信したか） → [[受信ログ]]
- トーンスキャン（CTCSS / DCS の検索）、周波数キャッチャー
- 懐中電灯、キーロック、バックライトの細かい設定、画面反転、コントラスト
- マルチブート（複数のファームを入れて起動時に選ぶ） → [[マルチブート]]
- パソコンからの画面ミラー・リモート操作（RxJa Tools の「ライブビューア」） → [[UV-Studio]]

## できないこと

| 機能 | 理由 |
|---|---|
| 送信（PTT、VOX、1750Hz、DTMF 送出、ロジャー音、ビーコンなど） | 受信専用だから。→ [[受信専用のしくみ]] |
| 送信に関係するメニュー（送信出力、送信トーン、オフセット、送信タイムアウトなど 24 項目） | 隠してあります |
| NOAA 気象放送、音声ガイド、ゲーム、追加アプリ（オーバーレイ） | ビルドから外しました（容量を日本語表示に回すため、または送信を伴うため） |
| 「すべての画面」の日本語化 | メニュー、メッセージ、よく見る画面を日本語化しています。周波数・数値・単位・略語（FM、VFO、CTCSS など）は、見やすさのためにわざと英語のままにしています。スペクトラム画面など、文字が小さい画面は英語のままです |

## 表記について

この説明書では、次のように書きます。

| 表記 | 意味 |
|---|---|
| **M** | MENU キー |
| **EXIT** | EXIT キー |
| **F** | F キー（ファンクションキー） |
| **UP / DOWN** | 上下キー（UV-K1 では左右に並んでいます） |
| **SIDE1 / SIDE2** | 側面の 2 つのキー（PTT の下） |
| **F+5** | F を押して離し、続けて 5 を押す |
| **5 長押し** | 5 を押したままにする |
| メニュー名 | 「ステップ（Step）」のように、日本語名と英語名を並べます。英語名は元の F4HWN と同じなので、F4HWN の情報を探すときに使えます |
