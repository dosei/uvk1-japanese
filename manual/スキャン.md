# スキャン

スキャンは、信号の入っている周波数（チャンネル）を、無線機が自動で探す機能です。信号が見つかると止まり、その音が聞こえます。

RxJa のスキャンは、次の 6 種類です。

| 種類 | 何を探すか | 始め方 |
|---|---|---|
| [周波数スキャン](#周波数スキャン) | いまのバンドの中を、周波数ステップずつ | 周波数モード（VFO）で `*` 長押し |
| [範囲スキャン](#範囲スキャン) | A と B の 2 つの周波数のあいだ | 周波数モードで `5` 長押し → `*` 長押し |
| [プリセット](#プリセット) | 特小・エアバンドなど、決まった周波数帯（範囲スキャンの一種） | `F` → `7`（または `7` 長押し）で選んで `M` |
| [チャンネルスキャン](#チャンネルスキャン) | 登録したチャンネルを、スキャンリストごとに | チャンネルモード（MR）で `*` 長押し |
| [周波数キャッチャー](#周波数キャッチャー) | 近くで出ている電波の周波数とトーン | `F` → `4`（または `4` 長押し） |
| [トーンの検索](#トーンの検索) | いまの周波数の CTCSS / DCS | `F` → `*` |

どれも、スキャンで見つけても**送信はしません**。RxJa は受信専用です（→ [[受信専用のしくみ]]）。

> [!NOTE]
> このページの内容は、RxJa のソースコードを読んで確かめたもので、主な動作は実機（UV-K1）でも確かめています。

## スキャン中のキー

周波数スキャン、範囲スキャン、チャンネルスキャンで共通です。

| キー | 動き |
|---|---|
| `M` / `PTT` | スキャンを止めて、**見つけた所に残る** |
| `EXIT` | スキャンを止めて、**始めた所に戻る** |
| `UP` / `DOWN` | スキャンの向きを変えて、次へ進む。信号で止まっているときは、その信号を飛ばして先へ |
| `M` 長押し | 信号で止まっているとき：いまのチャンネル（周波数）を**除外**して、スキャンを続ける（→ [除外](#除外)） |
| `*` 長押し | チャンネルスキャン：次のスキャンリストに切り替える。周波数スキャン・範囲スキャン：止める |
| `F` → `UP` / `DOWN` | チャンネルスキャン：スキャンリストを 1 つ前 / 次へ |
| 数字 2 けた | チャンネルスキャン：スキャンリストを選ぶ（`00` = ALL、`01`〜`24`、`25` = 混合） |

- サイドキーに「スキャン（SCAN）」を割り当てていれば、`*` 長押しと同じ動きになります（→ [[キー操作]]）。
- 隠しメニューの「矢印操作（SetNav）」で上下の向きを反対にしていると、`UP` / `DOWN` の向きも反対になります。

> [!IMPORTANT]
> 元の F4HWN Wiki には「スキャン中に `F` → `*` でスキャンリストを切り替える」とあります。RxJa（元の F4HWN v6.1.0 も同じ）では、`F` → `*` は**スキャンを止めて、トーンの検索を始めます**。リストを切り替えるときは、`*` 長押し、`F` → `UP` / `DOWN`、数字 2 けたを使ってください。

## 信号で止まったあと（SC再開）

信号を見つけて止まったあと、いつスキャンを再開するかは、メニューの「SC再開（ScnRev）」で決めます（→ [[メニュー一覧#sc再開scnrevの表示]]）。

| SC再開 | 動き |
|---|---|
| `再開しない`（STOP） | 信号が終わると、スキャンは止まったままになる。続けるときは、もう一度 `*` 長押し |
| `信号断後`（CARRIER） | 信号が途切れてから、設定した時間（0.25〜20 秒）待って、再開する。会話を最後まで聞くのに向く |
| `時間経過`（TIMEOUT） | 信号が続いていても、設定した時間（5 秒〜2 分）たったら、次へ進む。ずっと出ている信号（ビーコンや雑音）で止まり続けないようにする |

## SC速度（SetScn）

メニューの「SC速度（SetScn）」を `高速`（FAST）にすると、**チャンネルスキャンと範囲スキャン**が速くなります。信号の強さを先にざっと見て、信号が無いところは、周波数を合わせずに飛ばすためです。

- 周波数スキャン（範囲を決めないもの）は、`高速` にしても速さは変わりません。
- `高速` のときは、スキャンしている段の上の行に、最近見た信号の強さが小さな波形で出ます（→ [[画面の見かた]]）。
- 弱い信号を取りこぼすと感じたら、`標準`（NORMAL）に戻してください。

## 周波数スキャン

周波数モード（VFO）で、いまの周波数から上へ、周波数ステップずつ探していきます。

1. 周波数モードにする（`3` 長押し、または `F` → `3`）。
2. 始めたい周波数と、周波数ステップ（メニューの「ステップ（Step）」、または `F` → サイドキー）を合わせる。
3. `*` を長押しする。ステータスバーに `S` が出ます。

- いまのバンド（画面の `F1`〜`F7`）の中だけを回ります。上の端まで行くと、下の端に戻ります。

  | バンド | 範囲 |
  |---|---|
  | F1 | 18〜108 MHz |
  | F2 | 108〜137 MHz |
  | F3 | 137〜174 MHz |
  | F4 | 174〜350 MHz |
  | F5 | 350〜400 MHz |
  | F6 | 400〜470 MHz |
  | F7 | 470〜1300 MHz |

- 広い範囲を細かいステップで回ると、1 周に時間がかかります。探したい範囲が決まっているときは、[範囲スキャン](#範囲スキャン)が便利です。
- 周波数スキャンでは、[除外](#除外)は使えません（範囲スキャンでは使えます）。

## 範囲スキャン

A の段と B の段の周波数を、範囲の両端として、そのあいだだけを探します。たとえば「430.000〜440.000 MHz」だけを探す、という使い方です。

1. A と B を両方とも周波数モード（VFO）にして、範囲の両端の周波数を入れる（どちらが上でもかまいません）。
2. メインの段（`▶` の付いたほう）で、周波数ステップを合わせる。範囲スキャンは、このステップで進みます。
3. メインの段で `5` を長押しする。**範囲スキャンのモード**になり、B の段（メインでないほう）の代わりに `ScnRng` と、範囲の両端の周波数が出ます。
4. `*` を長押しすると、範囲の中でスキャンが始まります。

範囲スキャンのモードから抜けるには、次のどれかをします。

- もう一度 `5` を長押しする
- `EXIT` を長押しする
- `2` 長押し（または `F` → `2`）で A / B を入れ替える

範囲スキャンのモードのまま `F` → `5` でスペクトラムを開くと、スペクトラムもこの範囲を表示します（→ [[スペクトラム]]）。

範囲スキャンの画面では、まん中の行に `12/400` のような「いま何ステップ目か / 全部で何ステップか」と、進み具合のゲージが出ます（→ [[画面の見かた]]）。

## プリセット

特小（特定小電力無線）、エアバンド、国際 VHF、アマチュア無線の FM など、よく聞かれる周波数帯を一覧から選んで、範囲スキャンする機能です（RxJa v0.1.2 から）。範囲の両端・ステップ・変調・帯域幅がプリセットに入っているので、A と B に周波数を入れる必要はありません。

1. メイン画面で `F` → `7`（または `7` 長押し）。プリセットの一覧が開きます。
2. `UP` / `DOWN`（または数字キー）で選んで、`M` を押す。

スキャンが始まったあとは、ふつうの範囲スキャンと同じです（スキャン中のキー、止めたあとの範囲スキャンのモード、抜け方も同じ）。ただし、スキャン中に電源を切っても、次に電源を入れたときに再開はしません。

入っているプリセットの一覧や、選んだときに書き換わる設定は、[[受信モード#プリセット範囲スキャン]] を見てください。

## チャンネルスキャン

登録したチャンネル（メモリー）を、順に見ていきます。どのチャンネルを見るかは、**スキャンリスト**で決めます。

### スキャンリスト

スキャンリストは、`01`〜`24` の 24 個あります。チャンネルごとに、どのリストに入れるかを決めておきます。

| チャンネルの設定 | 意味 |
|---|---|
| `OFF` | どのリストにも入れない。チャンネルスキャンでは飛ばされる |
| `01`〜`24` | そのリストに入れる |
| `ALL` | すべてのリストに入れる（どのリストでスキャンしても見に行く） |

チャンネルのリストを決めるには、3 つの方法があります。

| 方法 | やりかた |
|---|---|
| 本体のメニュー | 「CH一覧（ChList）」で選ぶ（→ [[メニュー一覧]]） |
| 本体のキー | チャンネルモードで、そのチャンネルを表示して `5` を長押し。押すたびに `OFF` → `01` → `02` → … → `24` → `ALL` → `OFF` と変わり、そのまま保存されます |
| CHIRP | 追加フィールドの「Scanlists」で選ぶ。リストに名前を付けるのも CHIRP で（→ [[CHIRP]]） |

いまのチャンネルが入っているリストは、画面の段の右上に、白黒反転の小さな文字で出ます（`01`、`ALL`、`OFF`、名前を付けたリストは名前の先頭 3 文字）。

### 混合（MIX）— 選んだリストだけを回す

v1.2.0 から、**24 のリストのうち自分で選んだものだけ**をまとめて回す `混合`（MIX）が使えます。「01 と 05 と 12 だけ」のような使い方ができます。

- 「ｽｷｬﾝﾘｽﾄ（ScList）」を送ると、`01`〜`24` → `混合` → `ALL` の順に回ります。
- どのリストを入れるかは、`混合` を選んだ状態で `M` を押すと開く一覧で決めます（画面と操作は [[メニュー一覧#混合に入れるリストを選ぶ]]）。
- **チャンネル側の設定は変わりません**。チャンネルはこれまでどおり `01`〜`24` か `ALL` に入れておき、`混合` は「どのリストを回すか」だけを決めます。
- スキャン中は、数字の `25` でも `混合` に切り替えられます。

### スキャンのしかた

1. メニューの「ｽｷｬﾝﾘｽﾄ（ScList）」で、回すリストを選ぶ（`01`〜`24`、自分で選んだリストだけの `混合`、または全部の `ALL`）。
2. チャンネルモード（MR）にして、`*` を長押しする。

- 選んだリストにチャンネルが 1 つも無いときは、チャンネルの入っている次のリストに、自動で移ります。
- スキャン中は、ステータスバーの左に、いま回しているリスト（名前の 3 文字、番号、`混合` のときは `MIX`、または `ALL`）が出ます。
- スキャン中にリストを変えると、まん中の行に約 1 秒、`SCAN LIST 03` のように、変えた先のリストが出ます。その間はスキャンも待ちます。
- まん中の行には、`12/40` のような「リストの中で何番目か / リストのチャンネル数」と、進み具合のゲージが出ます。

### 優先スキャン

とくに聞き逃したくないチャンネルを 2 つまで決めて、スキャンの合間に何度も確かめに行かせる機能です。

1. 「優先CH1（PriCh1）」「優先CH2（PriCh2）」に、チャンネルを選ぶ（使わないほうは `なし`）。
2. 「SC優先（ScPri）」を ON にする。
3. チャンネルスキャンを始める。

- 優先スキャンが有効なときは、ステータスバーのリスト表示の後ろに `+` が付きます。
- 優先チャンネルを見に行っているときは、まん中の行に `P1` / `P2` と出ます。
- 優先スキャンが働くのは、チャンネルスキャンのときだけです。

## 除外

スキャン中に、同じ雑音や、聞かなくてよい信号で何度も止まるときは、そこを**除外**（スキャンで飛ばす）できます。

**信号で止まっているときに `M` を長押し**すると、除外してスキャンを続けます。

| スキャンの種類 | 除外されるもの | 取り消し |
|---|---|---|
| チャンネルスキャン | そのチャンネル（画面の右上に `EX` と出る）。`ALL` でスキャンしているときも除外される | 電源を入れ直すと**全部取り消し**。1 つだけ戻すときは、そのチャンネルで `5` 長押し（最初の 1 回は、除外の取り消しだけで、リストは変わりません） |
| 範囲スキャン | その周波数。最大 64 個（それを超えると、古いものから忘れる） | 範囲の両端か、ステップを変えると取り消し。電源を切っても取り消し |

> [!TIP]
> 除外は、その場だけの一時的なものです。ずっとスキャンから外したいチャンネルは、スキャンリストを `OFF` にしてください。

## 電源を切ったときのスキャン

スキャン中に電源を切ると、次に電源を入れたとき、**同じスキャンが自動で始まります**（チャンネルスキャンは、同じリストで。範囲スキャンは、同じ範囲で）。プリセットのスキャンだけは再開しません。スキャンを止めてから電源を切ると、次はふつうに起動します。

FM ラジオとスペクトラムも同じで、開いたまま電源を切ると、次に電源を入れたときにその画面が開きます。

## 周波数キャッチャー

近くで出ている電波の周波数を、すばやく拾う機能です。周波数を知らない相手でも、**すぐ近く（数メートル〜数十メートル）で送信していれば**、その周波数がわかります。見つけたあとは、続けて CTCSS / DCS のトーンも探します。

> [!NOTE]
> 周波数キャッチャーは、強い電波だけを拾う作りです。遠くの弱い電波は見つかりません。遠くの信号を探すときは、[周波数スキャン](#周波数スキャン)や[[スペクトラム]]を使ってください。

1. `F` → `4`（または `4` を長押し）。スキャン中なら、スキャンを止めてから開きます。
2. 画面に `周波数検索中` と出て、点滅します。
3. 近くの電波を見つけると、`周波数:145.50000` のように周波数が出て、`トーン検索中` に変わります。
4. トーンが見つかると `完了` と出て、`CTCSS:88.5Hz` や `DCS:D023N` のようにトーンが出ます。約 16 秒たっても見つからないときは、`完了` と `トーン:なし` になります（周波数だけわかった状態）。

| キー | 動き |
|---|---|
| `M` | 見つけた周波数を保存する（下の手順） |
| `*` | もう一度、はじめから探す |
| `EXIT` | やめて、メイン画面に戻る。保存の確認中なら、確認を取り消す |
| `PTT` | やめる |
| そのほか | 「ピピッ」と鳴るだけ |

### 見つけた周波数を保存する

`M` を押すと、見つけた周波数は、近いほうの 2.5 kHz か 6.25 kHz の倍数に丸められ、周波数ステップもそれに合わせられます。

- **周波数モード（VFO）から開いたとき**：`保存?` と出るので、もう一度 `M`。いまの VFO に入ります。
- **チャンネルモード（MR）から開いたとき**：`保存:` とチャンネル番号が出ます。`UP` / `DOWN` か数字 4 けたで保存先を選んで `M`、`保存?` でもう一度 `M`。

> [!WARNING]
> 保存すると、保存先のチャンネル（VFO）の**ほかの設定は初期値に戻ります**。入るのは、周波数・ステップ・見つけたトーンだけです。変調は FM（108〜137 MHz の VFO だけは AM）、帯域幅は広帯域、コンパンダーは OFF になり、**スキャンリストは `OFF`** になります（チャンネル名はそのまま残ります）。すでに使っているチャンネルに上書きするときは注意してください。

保存したあとも、周波数キャッチャーの画面のままです。`EXIT` でメイン画面に戻ります。

## トーンの検索

いま聞いている周波数で、相手が使っている CTCSS / DCS のトーンを探します（変調が FM のとき）。周波数は変わりません。

1. 相手の信号が出ている周波数（チャンネル）に合わせる。
2. `F` → `*`。スキャン中なら、スキャンを止めてから始めます。
3. 画面に `トーン検索中` と出ます。相手が送信しているあいだに見つかると、`完了` とトーンが出ます。約 16 秒たっても見つからないときは `失敗` と出ます（`*` でやり直せます）。
4. `M` → `保存?` で `M`（チャンネルモードのときは、周波数キャッチャーと同じく、保存先のチャンネルを選んでから）。**トーンだけ**が書き換わります。周波数、名前、スキャンリストなどは、そのままです。

メニューの「CTCSS（RxCTCS）」「DCS（RxDCS）」からも、同じようにトーンを探せます（→ [[メニュー一覧]]）。

## 2 波受信とスキャン

- スキャンは、メインの段（`▶` の付いたほう）で行います。
- 2 波受信（`DR`）は、スキャンのあいだ止まります（ステータスバーのマークが一時停止に変わります）。
- 受信方式が `サブのみ`（XB）のときは、スキャンのあいだだけ一時的に解除され、スキャンを止めると元に戻ります。
