# キー操作

このページでは、RxJa のキー操作を画面ごとにまとめます。元の F4HWN Fusion v6.1.0 とほぼ同じですが、受信専用にしたことで**何もしなくなったキー**や、**元の F4HWN Wiki と動きがちがうところ**があります。それぞれの表で印をつけています。

> [!NOTE]
> このページの内容は、RxJa のソースコードを読んで確かめたもので、主な動作は実機（UV-K1）でも確かめています。

## 押し方の書き方

| 表記 | 押し方 |
|---|---|
| **5** | 5 を短く押して離す |
| **5 長押し** | 5 を押したままにする（約 1 秒） |
| **F+5** | F を押して**離し**、続けて 5 を押す。F を押すと画面右上に `F` が出ます |
| **ピピッ** | 低い音の 2 回ビープ。「その操作はできません」の合図です |

キーの名前は次のとおりです。

| 名前 | キー |
|---|---|
| **M** | MENU |
| **EXIT** | EXIT |
| **F** | F キー（ファンクションキー） |
| **UP / DOWN** | 上下キー（UV-K1 では左右に並んでいます。向きはメニューの「矢印操作（SetNav）」で入れ替えられます） |
| **SIDE1 / SIDE2** | 側面の PTT の下にある 2 つのキー |
| **PTT** | 側面のいちばん大きなキー（RxJa では送信しません） |

## 早見表（メイン画面）

よく使う操作だけを抜き出しました。詳しくは下の表を見てください。

| やりたいこと | 操作 |
|---|---|
| メニューを開く | M |
| チャンネル ⇔ 周波数（VFO）を切り替える | F+3 |
| 上下の段（A / B）を入れ替える | F+2 |
| スキャンを始める | * 長押し |
| スキャンを止める（見つけた所に残る） | M または PTT |
| スキャンを止める（始めた所に戻る） | EXIT |
| スケルチを変える | F+UP / F+DOWN |
| スペクトラム（バンドスコープ） | F+5 |
| FM ラジオ | F+0 |
| プリセット（特小・エアバンドなどを範囲スキャン） | F+7 |
| 周波数キャッチャー | F+4 |
| トーン（CTCSS / DCS）を探す | F+* |
| キーロック / 解除 | F 長押し |
| 懐中電灯・モニターなど | サイドキー（割り当てによる） |

## メイン画面のキー

### 数字キー

メモリー（チャンネル）モードでは**チャンネル番号**、VFO（周波数）モードでは**周波数**の入力になります。

- **チャンネル番号**：最大 4 けた。4 けた打つとすぐ切り替わります。1〜3 けたで止めると、8 秒後にそのチャンネルに切り替わります。
- **周波数**：MHz の単位で 6 けた（1000MHz 以上は 7 けた）。例：`145000` → 145.000MHz、`433500` → 433.500MHz。
- **スキャン中**：2 けたでスキャンリストを選びます（→ [[スキャン]]）。
- 入力の途中で **EXIT** を押すと 1 けた消えます。全部消すと入力前の状態に戻ります。

### 数字キーのもう一つの機能（F+数字 / 長押し）

たいていは「F+数字」と「数字の長押し」が同じ機能です。ちがうものは太字にしています。

| キー | F+キー | 長押し | 補足 |
|---|---|---|---|
| **0** | FM ラジオのオン / オフ | 同じ | → [[FMラジオ]] |
| **1** | チャンネルモード：いまのチャンネルを VFO にコピー<br>VFO モード：次のバンドへ | 同じ | コピーは、スキャン中は受け付けません。バンドは 470MHz 帯の次が 1GHz 帯に飛び、最後まで行くと最初に戻ります |
| **2** | A / B 入れ替え | 同じ | 範囲スキャンのモードからも抜けます |
| **3** | VFO ⇔ メモリーの切り替え | 同じ | |
| **4** | 周波数キャッチャー | 同じ | スキャン中なら止めてから開きます（→ [[スキャン]] の「周波数キャッチャー」） |
| **5** | スペクトラム | **VFO モード：範囲スキャンのオン / オフ**<br>**メモリーモード：このチャンネルのスキャンリストを切り替え** | → [[スペクトラム]]、[[スキャン]] |
| **6** | 送信出力の値を切り替える | 同じ | ⚠ **RxJa では意味がありません**（保存される値が変わるだけで、電波には関係しません） |
| **7** | **プリセット** | 同じ | ⚠ 元の F4HWN では VOX です。RxJa では、範囲スキャンのプリセットの一覧を開きます（→ [[受信モード#プリセット範囲スキャン]]） |
| **8** | バックライトをつける | **周波数反転（リバース）のオン / オフ** | |
| **9** | バックライトをふだんの点灯時間に戻す | **「1 コール（1 Call）」のチャンネルへ移動** | メニューの「1コール（1 Call）」で決めたチャンネル |

<details>
<summary>5 長押し（メモリーモード）の細かい動き</summary>

チャンネルのスキャンリストが、`OFF`（スキャンしない）→ `1` → `2` → … → `24` → `ALL`（全リスト）→ `OFF` の順に切り替わります。変えた値はそのチャンネルに保存されます。

そのチャンネルがスキャンから**除外**されている（画面に `EX` と出ている）ときは、最初の 1 回は除外を取り消すだけで、リストは変わりません。
</details>

### そのほかのキー

| キー | 短く押す | F+キー | 長押し |
|---|---|---|---|
| **M** | メニューを開く（分類の一覧から）。<br>スキャン中：止めて、見つけた所に残る | — | スキャン中：いまの周波数・チャンネルを**除外**してスキャンを続ける。<br>それ以外：「M長押し（M Long）」に割り当てた機能 |
| **EXIT** | 入力を 1 けた消す。<br>スキャン中：止めて、始めた所に戻る | — | 入力の取り消し、モニターを切る、範囲スキャンのモードから抜ける |
| **\*** | DTMF 入力のモードに入る（下の注意を参照） | トーン（CTCSS / DCS）の検索。スキャン中なら止めてから始めます | スキャン開始 |
| **UP / DOWN** | VFO：周波数を 1 ステップ上下。<br>メモリー：次のチャンネル。<br>スキャン中：スキャンの向きを変える | スケルチを上下（0〜9）。<br>スキャン中：スキャンリストを切り替え | 押し続けると続けて動く |
| **F** | F の状態にする / 取り消す | — | キーロック / 解除 |
| **SIDE1** | サイドキーの機能（下記） | ステップを大きく（VFO モードでは保存される） | サイドキーの機能 |
| **SIDE2** | サイドキーの機能（下記） | ステップを小さく | サイドキーの機能 |

> [!NOTE]
> **\* を短く押すと DTMF 入力のモード**になります（元の F4HWN と同じ動き）。数字や記号を打てますが、RxJa は送信しないので**何にも使われません**。間違えて入ったときは、8 秒ほど何も押さなければ自動で抜けます。EXIT 長押しでもすぐに抜けられます。

> [!NOTE]
> 元の F4HWN Wiki には「スキャン中に F+* でスキャンリストを切り替える」とありますが、RxJa（元の F4HWN v6.1.0 のコードも同じ）では、**F+\* はスキャンを止めてトーンの検索を始めます**。スキャン中にリストを切り替えるのは、* 長押し、F+UP / F+DOWN、または数字 2 けたです。

### 操作できないとき

- トーンの検索や周波数キャッチャーが動いている間は、数字キーと F、サイドキーは「ピピッ」となって効きません。
- スキャン中や範囲スキャンのモードで \* を短く押すと「ピピッ」となります。

## サイドキー（SIDE1 / SIDE2 / M 長押し）

サイドキーは、短押し・長押しのそれぞれに好きな機能を割り当てられます。割り当てはメニューの次の項目で変えます（→ [[メニュー一覧]]）。

| メニュー | キー |
|---|---|
| F1短押（F1Shrt） | SIDE1 を短く押す |
| F1長押（F1Long） | SIDE1 を長押し |
| F2短押（F2Shrt） | SIDE2 を短く押す |
| F2長押（F2Long） | SIDE2 を長押し |
| M長押（M Long） | M を長押し（スキャン中を除く） |

「初期化（Reset）→ `ALL`」をしたあとの割り当ては、`F1短押 = モニター`、`F2短押 = スキャン`、ほかは `なし` です（ソースコードから読み取った値。実機では未確認）。

- 短押しの機能は**離したとき**、長押しの機能は**押したまま一定時間たったとき**に動きます。
- サイドキーは、メイン画面だけでなく、FM ラジオや受信ログの画面でも使えます。

### 割り当てられる機能

| 日本語表示 | 英語表示 | 動き | RxJa |
|---|---|---|---|
| なし | NONE | 何もしない | ○ |
| フラッシュライト | FLASHLIGHT | 懐中電灯（本体上部の LED）の点灯 / 消灯 | ○ |
| モニター | MONITOR | スケルチを開けて雑音ごと聞く（弱い信号を探すとき） | ○ |
| スキャン | SCAN | スキャンの開始・停止（下記） | ○ |
| FMラジオ | FM RADIO | FM ラジオのオン / オフ | ○ |
| キーロック | LOCK KEYPAD | キーロック / 解除 | ○ |
| VFO A/B | VFO A/B | A / B 入れ替え | ○ |
| VFO メモリ | VFO/MEM | VFO ⇔ メモリーの切り替え | ○ |
| 変調切替 | MODE | FM → AM → USB → FM の順に切り替え（周波数モードでは保存される。チャンネルモードでは一時的な変更で、残すには「CH保存」→ [[メニュー一覧#チャンネルの保存削除]]） | ○ |
| 受信方式 | RX MODE | 受信方式を順に切り替え（メニューの「受信方式（RxMode）」と同じ。v1.2.0 からは全波受信の 2 つも回るので 6 とおり） | ○ |
| メインのみ | MAIN ONLY | 2 波受信とメインのみの切り替え | ○ |
| 帯域幅切替 | WIDE/NARROW | 広帯域 / 狭帯域の切り替え | ○ |
| 消音 | MUTE | 音を消す / 戻す | ○ |
| 受信音質 | RxA | 受信音の音質（メニューの「受信音質（SetRxA）」）を切り替え | ○ |
| 受信ログ | RF LOG | 受信ログの画面を開く。**これを割り当てると受信ログの記録が始まります**（→ [[受信ログ]]） | ○ |
| 送信出力 | POWER | — | ✕ `N/A` |
| ビーム | BEAM | — | ✕ `N/A` |
| 高出力 | POWER HIGH | — | ✕ `N/A` |
| オフセット解除 | REMOVE OFFSET | — | ✕ `N/A` |
| フォックスハント | FOX HUNT | — | ✕ `N/A` |
| ビーコン | BEACON | — | ✕ `N/A` |

✕ の機能は送信に関係するので、RxJa では使えません。メニューや CHIRP で割り当てることはできますが、表示は `N/A` になり、押すと「ピピッ」と鳴るだけです。

**スキャン（SCAN）の動き**

| いまの状態 | 押したとき |
|---|---|
| スキャンしていない | スキャンを始める |
| 周波数（VFO）のスキャン中、範囲スキャン中 | スキャンを止める |
| チャンネルのスキャン中 | **次のスキャンリストに切り替える**（止まりません。止めるときは M か EXIT） |
| トーンの検索中 | 何もしない |
| FM ラジオの画面 | **FM の自動スキャン**（登録してある FM の 48 局がすべて消えます → [[FMラジオ#自動スキャン]]）。自動スキャン中なら止める |

**FM ラジオの画面で使えない機能**：送信出力、モニター、VFO A/B、VFO メモリ、変調切替、受信方式、メインのみ、帯域幅切替、受信音質（「ピピッ」と鳴ります）。

> [!WARNING]
> 初期化（`ALL`）のあとは、サイドキー 2 の短押しが「スキャン」です。FM ラジオの画面でサイドキー 2 を押すと、**FM の登録局がすべて消えて**自動スキャンが始まります。

### アクションピッカー（機能をその場で選ぶ）

割り当てていない機能も、その場で選んで使えます。

1. **F を押して離し、SIDE1 か SIDE2 を長押し**する。
2. 画面に機能の名前が出るので、**UP / DOWN** で選ぶ（「なし」は飛ばされます）。
3. **M** で実行。**EXIT** か **F** でやめる。

使えない機能は `N/A` と表示されます。キーロックしたとき、電池残量低下の表示が出たとき、メイン画面から離れたときは自動で閉じます。PTT を押すと閉じて、PTT を押したときの動き（下記）になります。

## PTT

RxJa は送信しないので、PTT はほとんどの場面で「送信禁止」を知らせるだけです。ただし、いくつかの場面では**止める**キーとして使えます。

| 場面 | PTT を押したとき |
|---|---|
| ふだんのメイン画面 | **`送信禁止`**（日本語データが無いときは `TX DISABLE`）と出て「ピピッ」。表示は PTT を離して 2.5 秒ほどで消えます |
| チャンネル / 周波数のスキャン中 | スキャンを止めて、見つけた所に残る（M と同じ） |
| トーンの検索中・周波数キャッチャー | 検索を止める |
| FM ラジオの自動スキャン中 | スキャンを止めて、そこを聞く |
| FM ラジオを聞いているとき | メイン画面に `送信禁止` が出て、2.5 秒ほどで FM ラジオの画面に戻る |
| DTMF 入力のモード | 入力した文字を記録して `送信禁止`（何も送信されません） |
| キーロック中で、「ﾛｯｸ対象（SetLck）」に PTT が入っている | ロック中の「ピピッ」と `F長押しで解除` |
| スペクトラムの画面 | 詳細モニターを開く（→ [[スペクトラム]]） |
| 受信ログで「消去しますか」の確認中 | 確認を取り消す |

送信はプログラムの何か所もで止めてあります（→ [[受信専用のしくみ]]）。

## キーロック

### かけ方・はずし方

- **F 長押し**で、ロック / 解除を切り替えます（メイン画面、FM ラジオ、受信ログの画面で使えます。メニューの中では使えません）。
- サイドキーに「キーロック」を割り当てて使うこともできます。
- ロックの状態は保存されるので、電源を切って入れ直してもロックされたままです。
- ロック中は、画面右上に鍵のマークが出ます。

### ロック中の動き

- F 以外のキーを押すと「ピピッ」と鳴り、`F長押しで解除` と 2 秒ほど表示されます。
- **サイドキー**（SIDE1、SIDE2、M 長押し）は、「ﾛｯｸ対象（SetLck）」に「機能」が入っていなければ使えます。
- **PTT** は、「ﾛｯｸ対象」に PTT が入っていなければ、ふだんどおり `送信禁止` が出ます。

「ﾛｯｸ対象（SetLck）」の値：

| 表示 | 英語 | ロックされるもの |
|---|---|---|
| キー | KEYS | 前面のキー |
| キー +機能 | KEYS + ACTIONS | 前面のキーとサイドキー |
| キー +PTT | KEYS + PTT | 前面のキーと PTT |
| キー +機能 +PTT | KEYS + ACTIONS + PTT | 全部 |

### 自動ロック（KeyLck）

メニューの「自動ﾛｯｸ（KeyLck）」で、キーを触らない時間が続くと自動でロックできます。

- `OFF`、または 15 秒きざみで最大 10 分（`00:15` 〜 `10:00`）。
- キーを押すたびに、また電源を入れたときに、時間は最初から数え直します。
- スキャン中、トーンの検索中、FM ラジオのスキャン中、メニューを開いているとき、DTMF 入力のモードでは数えません。

## 元の F4HWN Wiki とちがうところ（まとめ）

1. **F+7 / 7 長押し**は、VOX ではなく、範囲スキャンのプリセットを開きます（RxJa v0.1.2 から。VOX は RxJa にはありません）。
2. **F+6 / 6 長押し**は送信出力の値を変えますが、意味はありません。サイドキーの「送信出力」は `N/A` です。
3. スキャン中の **F+\*** は、リストの切り替えではなく、スキャンを止めてトーンの検索を始めます。
4. スキャンの**除外**は、`ALL` でスキャンしているときも効きます。除外は**電源を入れ直すと全部取り消されます**（→ [[スキャン]]）。
5. \* 短押しの DTMF 入力は残っていますが、何も送信しません。
6. 「ﾛｯｸ対象」の PTT の選択肢は残っています。PTT をロックすると、PTT を押したときに `送信禁止` ではなくロックの表示が出ます。
7. 受信ログは、サイドキーに「受信ログ」を割り当てたときだけ記録され、送信の記録はありません（→ [[受信ログ]]）。
