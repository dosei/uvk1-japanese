# 本体の仕様

このページでは、UV-K1 本体の仕様（受信できる周波数、画面、メモリーの量、電池、大きさ、中の部品など）をまとめます。UV-K1 には UV-K1 L・UV-K1(8) などのモデルがありますが、中身は同じです（→ 下の「モデルの種類」）。

画面・マイコン・メモリー・電池などの**本体の部品は、どのファームを書き込んでも変わりません**。一方で、受信できる周波数やメモリーチャンネルの数などは**ファームで決まる**ので、純正ファームのときと RxJa のときで違います。そこで、ファームで変わる項目は「メーカー公表値（純正ファーム）」と「RxJa」に分けています。

> [!NOTE]
> - 「メーカー公表値」は Quansheng の[取扱説明書](https://www.manualslib.com/manual/4204387/Quansheng-Uv-K1.html)と[仕様書](https://uv-k1.com/wp-content/uploads/2025/11/uv-k1-spec-sheet.pdf)の値です。この 2 つで値が違う項目は、両方を書いています。
> - 「RxJa」の値は、ファームのソースコードから読み取ったものです。実機で測ったものではありません。
> - 中の部品は、分解写真（[armel/k1-teardown](https://github.com/armel/k1-teardown)）とソースコードからわかったことです。

## ひと目で

### ファームで変わるもの

| 項目 | メーカー公表値（純正ファーム） | RxJa |
|---|---|---|
| 受信できる周波数 | 50〜600 MHz（76〜108 MHz は FM 放送のみ） | **18〜1300 MHz**（63〜84 MHz を除く）※端のほうは感度が落ちます |
| 送信 | 136〜174 MHz / 400〜470 MHz、5 W 以下 | **しない**（→ [[受信専用のしくみ]]） |
| 変調 | FM（広帯域・狭帯域）、AM（108〜136 MHz のみ） | FM / AM / USB（どの周波数でも） |
| 周波数ステップ | 2.5〜25 kHz の 6 種類 | 0.01〜500 kHz の 24 種類 |
| メモリーチャンネル | 200 | **1024** |
| FM ラジオ | 76〜108 MHz、20 局 | 64〜108 MHz（4 つの範囲から選ぶ）、48 局 |

### 本体の部品（どのファームでも同じ）

| 項目 | 値 |
|---|---|
| 画面 | 1.44 インチ、白黒の液晶、**128×64 ドット** |
| マイコン | PY32F071（フラッシュ 128 KB、RAM 16 KB） |
| データ保存用のメモリー | SPI フラッシュ 2 MB |
| 電池 | 1400 mAh（標準）／ 2500 mAh（大容量） |
| 充電 | USB Type-C（本体）、充電台 |
| パソコンとの通信 | 2 通り。① 本体の **USB Type-C**（ふつうの USB ケーブル。パソコンからは仮想シリアルポート（USB CDC）に見える）／② **イヤホン・データ端子**（ケンウッド型 2 ピン）に専用の USB ケーブル（K プラグ）をつなぐ（シリアル通信、38400 bps） |
| 大きさ・重さ | 98×59×33.8 mm、190 g（UV-K1、標準電池） |

- パソコンとの通信は、RxJa ではどちらの経路でも同じように使えます（RxJa Tools・UV Studio、`upload.py`、CHIRP など。→ 下の「端子・キー・ランプ」、[[日本語データの転送]]）。
- 画面の大きさ・電池・大きさ・重さはメーカー公表値です。マイコンとメモリーは、メーカーは公表しておらず、分解写真とソースコードからわかったものです。
- 「受信できる周波数」がファームで変わるのは、無線チップ（BK4829）がもともと広い範囲を受信でき、どこまで使うかをファームが決めているからです。

## モデルの種類

UV-K1 には、前面パネルと電池の違う 4 つのモデルがあります。名前の **「L」は大容量の電池**付き、**「(8)」は前面が金属パネル**のものです。中の部品（マイコン・無線チップ・メモリー・画面）はどれも同じで、RxJa も同じファームを書き込みます（→ [[はじめに#対応機種]]）。

| モデル | 前面パネル | 電池 | 大きさ・重さ |
|---|---|---|---|
| **UV-K1** | 樹脂 | 1400 mAh | 98 × 59 × 33.8 mm、190 g |
| **UV-K1 L** | 樹脂 | 2500 mAh（電池の分だけ下に長く、高さは UV-K5 と同じくらい） | 120.3 × 59 × 35.8 mm、260 g |
| **UV-K1(8)** | **金属** | 1400 mAh | UV-K1 より約 10 g 重い |
| **UV-K1(8) L** | **金属** | 2500 mAh | UV-K1 L より約 10 g 重い |

- UV-K1(8) / UV-K1(8) L は、金属パネルのほかに、電源つまみが太く、PTT の形も違います（→ 下の「UV-K1(8) との違い」）。
- 「(8)」が何を表すのか、メーカーの説明は見つかりませんでした。「8 MB のフラッシュ」の意味だとする説明もありますが、裏付けは見つかりませんでした（F4HWN も RxJa も、全モデルを 2 MB として扱っています）。
- 2026 年 4 月からは、上のモデルの**透明ケース版**も売られています。オレンジの **UV-K1s** は今後のモデルとして予告されていて、外観だけの違いとされています。どちらも、F4HWN・RxJa で動いたという報告はまだ見つかっていません。
- 同じ PY32F071 を使う **UV-K5 V3** と **UV-K5(8) V3** にも、RxJa は同じファームを書き込みます。UV-K5 でも「(8)」は外観違いのモデルです（→ 下の「UV-K5 V3 との違い」）。旧型の UV-K5 / K5(8) の V1・V2 は中身が違い、使えません。

## 受信

### 受信できる周波数

**メーカー公表値**（純正ファーム）。受信感度は、FM は 12 dB SINAD、ワイド FM は 20 dB SINAD、AM は 10 dB S/N での値です（数字が小さいほど、弱い電波まで聞けます）。

| 周波数（MHz） | 受信感度 |
|---|---|
| 50〜76 | -121 dBm |
| 76〜108（FM 放送） | -110 dBm |
| 108〜136 | -121 dBm（AM は -113 dBm） |
| 136〜174 | -123 dBm |
| 174〜350 | -123 dBm |
| 350〜400 | -123 dBm |
| 400〜470 | -123 dBm |
| 470〜600 | -121 dBm |

**RxJa**（元の F4HWN と同じ）では、**18〜1300 MHz** を受信できるようにしてあります。

- **63〜84 MHz は受信できません。** 無線チップ（BK4829）が受信できない範囲なので、ファームがこの範囲の周波数を受け付けません（`App/frequencies.c`）。
- メーカーが保証しているのは 50〜600 MHz だけです。それより外は、**感度が落ちたり、まったく聞こえなかったりします。** 実際にどこまで聞けるかは機体によります。
- ソースコードのコメントには「630〜760 MHz も受信できない」と書かれている箇所があります（ファームは受け付けます）。実際に聞けるかどうかは確かめていません。
- 参考：F4HWN を入れた UV-K1 で、FM の感度を 80 / 145 / 433 MHz で約 -129 dBm、AM を 120 MHz で約 -116 dBm と測った記事があります（[JH1LHV](https://www.jh1lhv.tokyo/entry/2026/04/01/174515)）。

周波数モード（VFO）では、この範囲を 7 つのバンド（`F1`〜`F7`）に分けています。

| バンド | 範囲（MHz） |
|---|---|
| F1 | 18〜108 |
| F2 | 108〜137 |
| F3 | 137〜174 |
| F4 | 174〜350 |
| F5 | 350〜400 |
| F6 | 400〜470 |
| F7 | 470〜1300（1000 MHz 以上は画面に `F7+` と出ます） |

FM 放送（76〜108 MHz など）は、ふつうの受信とは別の部品（BK1080）で聞きます。→ [[FMラジオ]]

### 変調・帯域幅・ステップ

| 項目 | メーカー公表値 | RxJa |
|---|---|---|
| 変調 | FM（16K0F3E＝広帯域、11K0F3E＝狭帯域）、AM は 108〜136 MHz のみ | FM / AM / USB。どの周波数でも選べる |
| 帯域幅 | 広帯域（25 kHz 間隔）／狭帯域（12.5 kHz 間隔） | 広帯域（W）／狭帯域（N） |
| 周波数ステップ | 2.5 / 5 / 6.25 / 10 / 12.5 / 25 kHz | 0.01 / 0.05 / 0.1 / 0.25 / 0.5 / 1 / 1.25 / 2.5 / 5 / 6.25 / 8.33 / 9 / 10 / 12.5 / 15 / 20 / 25 / 30 / 50 / 100 / 125 / 200 / 250 / 500 kHz |

- 8.33 kHz は、ヨーロッパなどのエアバンドのチャンネル間隔です。このステップのときは、入れた数字をエアバンドのチャンネルの周波数に直します（→ [[トラブルシューティング]]）。

### FM ラジオ

| 項目 | メーカー公表値 | RxJa |
|---|---|---|
| 範囲 | 76〜108 MHz | 76〜108 / 76〜90 / 64〜76 / 87.5〜108 MHz から選ぶ |
| 登録できる局の数 | 20 | 48 |

## 送信（参考）

RxJa では送信しません。以下は、純正ファームでの**メーカー公表値**です。

| 項目 | 値 |
|---|---|
| 送信できる周波数 | 仕向け地によって違う。NORMAL 版 136〜174 / 400〜470 MHz、FCC 版 144〜148 / 420〜450 MHz、CE/UKCA 版 144〜146 / 430〜440 MHz、IC 版 144〜148 / 430〜450 MHz |
| 送信出力 | 5 W 以下（H / M / L の切り替え） |
| 送信時の電流 | 1.5 A 以下 |
| 周波数安定度 | ±1 ppm |

> [!IMPORTANT]
> UV-K1 は技適を取っていません。日本で電波を出すと電波法違反です。RxJa を入れても技適を取ったことにはなりません。

## 画面

| 項目 | 値 |
|---|---|
| 大きさ | 1.44 インチ（メーカー公表値） |
| 種類 | 白黒の液晶（バックライト付き） |
| ドット数 | **横 128 × 縦 64** |
| 画面の縦横比 | 横：縦 ≒ **1.37：1**（表示部はおよそ 29〜30 × 21〜22 mm）。ドット数の比の 2：1 より縦長 |
| 1 ドットの形 | 正方形ではなく、**縦が横の約 1.45 倍**の長方形 |
| 表示の制御チップ | ST7565（互換品） |
| 明るさ | 11 段階（0〜10）。メニューの「照明最小（BLMin）」「照明最大（BLMax）」で選ぶ |
| コントラスト | 1〜15（初期値 10）。メニューの「画面濃度（SetCtr）」で選ぶ |

- 画面のいちばん上の 8 ドットがステータスバー、その下の 56 ドットが本文です（→ [[画面の見かた]]）。
- 日本語は、1 文字 12×12 ドットで表示します。1 行に全角 10 文字（半角 21 文字）、画面に 4 行ほど入ります。
- 起動画面の絵（RxJa Tools・UV Studio で書き込めるもの）も 128×64 ドットの白黒です（→ [[UV-Studio]]）。ドットが縦長なので、パソコンで正方形のドットで描いた絵は、本体では縦に伸びて見えます。
- このウィキの画面の図は、実機に合わせて 1 ドットを横 4 × 縦 6 の比（1.5 倍）で描いています。

## メモリーの量

### マイコン（PY32F071）

| 項目 | 値 | RxJa で使っている量 |
|---|---|---|
| CPU | Arm Cortex-M0+、48 MHz で動作 | — |
| フラッシュ（ファームを入れる場所） | 128 KB。そのうち 10 KB は工場で書かれたブートローダー（書き換えない）、**ファームに使えるのは 118 KB（120,832 バイト）** | 108,952 バイト（約 90%、v1.2.0） |
| RAM | 16 KB（16,384 バイト） | 約 12,000 バイト（約 73%、スタックを含む） |

ファームに使える場所が 118 KB しかないので、日本語のフォントと訳は本体のフラッシュには入れず、下の SPI フラッシュに入れています（→ [[日本語データの転送]]）。

### SPI フラッシュ（PY25Q16、2 MB）

設定・チャンネル・校正データ・起動画面の絵・日本語データなどは、マイコンの外にある 2 MB（2,097,152 バイト）のフラッシュに入っています。旧型の UV-K5 にあった EEPROM はなく、その代わりをこのフラッシュがしています。

| アドレス | 中身 | 大きさ |
|---|---|---|
| 0x000000〜 | 設定・チャンネル・名前・VFO（マルチブートの設定 0） | 64 KB |
| 0x010000〜 | **校正データ**（機体ごとに違う。[[ファームの書き込み]] でバックアップするもの） | 512 バイト |
| 0x011000〜 | 起動画面の絵 | 4 KB |
| 0x020000〜0x0BFFFF | マルチブートのファームスロット 0〜4（→ [[マルチブート]]） | 128 KB × 5 |
| 0x0C0000〜0x0FFFFF | マルチブートの設定 1〜4 | 64 KB × 4 |
| 0x100000〜0x101FFF | マルチブートの状態 | 8 KB |
| 0x102000〜0x121FFF | 追加アプリ（オーバーレイ）用。RxJa では使わない | 128 KB |
| **0x122000〜0x14BFFF** | **RxJa の日本語データ（`ja_res.bin`）** | 168 KB（いまのデータは約 139 KB） |
| 0x14C000〜 | 音声ガイドのデータ（工場で書かれたもの）。RxJa では使わない | — |
| 0x1E0000〜0x1E7FFF | 受信ログ（1024 件）（→ [[受信ログ]]） | 32 KB |

### 記録できる数

| 項目 | メーカー公表値 | RxJa |
|---|---|---|
| メモリーチャンネル | 200 | 1024（名前は 10 バイトまで。日本語は全角 5 文字・半角カナ 10 文字） |
| スキャンリスト | — | 24 本（→ [[スキャン]]） |
| FM 放送局 | 20 | 48 |
| NOAA 気象チャンネル | 10 | なし（ビルドから外しています） |
| 受信ログ | — | 1024 件（いっぱいになると、古いものから消えて新しいものに入れ替わります） |

## 電池と電源

| 項目 | 値 |
|---|---|
| 電池 | リチウムイオン、2 セル（7.4 V）。**標準 1400 mAh**／**大容量 2500 mAh** |
| 満充電の電圧 | 約 8.3〜8.4 V |
| 充電 | 本体の USB Type-C、または付属の充電台。充電中は青い LED が点きます |

- 大容量の電池の容量は、取扱説明書では 2500 mAh、仕様書では 2800 mAh と書かれています。F4HWN（RxJa）のメニューは 2500 mAh としています。
- 仕様書によると、大容量の電池には電池そのものにも USB Type-C があります。
- 電池の残り（％）は、電池の電圧から計算しています。メニューの「電池種類（BatTyp）」で、使っている電池（`1400mAh K1` か `2500mAh K1`）を選んでください（→ [[メニュー一覧]]）。

  | 電池種類 | 100% | 0% |
  |---|---|---|
  | 1400mAh K1 | 8.28 V | 6.30 V |
  | 2500mAh K1 | 8.39 V | 6.23 V |

  UV-K1 用の 2 つの表は、元の F4HWN でも「推定値」とされています。％は目安と考えてください。

## 大きさ・重さ・使う環境

メーカー公表値です。

| 項目 | 標準電池（1400 mAh） | 大容量電池（2500 mAh） |
|---|---|---|
| 大きさ（幅×高さ×厚さ） | 98 × 59 × 33.8 mm | 120.3 × 59 × 35.8 mm |
| 重さ | 190 g | 260 g |

UV-K1 と UV-K1 L の値です。UV-K1(8) / UV-K1(8) L は、金属パネルの分だけそれぞれ約 10 g 重くなります（→ 上の「モデルの種類」）。

| 項目 | 値 |
|---|---|
| 使える温度 | 取扱説明書は 0〜40℃、仕様書は -20〜+60℃ |
| スピーカーの出力 | 0.5 W 以上（ひずみ 10% 以下） |
| アンテナのインピーダンス | 50 Ω |

## 端子・キー・ランプ

| 部分 | 内容 |
|---|---|
| アンテナ端子 | SMA（本体側がメス）※販売店の情報。取扱説明書には書かれていません |
| USB Type-C | 充電と、パソコンとの通信の両方に使えます。パソコンからは<strong>仮想シリアルポート（USB CDC）</strong>に見えます。RxJa Tools・UV Studio、`upload.py`、CHIRP はここを使います |
| イヤホン・データ端子 | ケンウッド型の 2 ピン（3.5 mm と 2.5 mm）。専用ケーブルで、パソコンとシリアル通信（38400 bps）もできます |
| キー | 前面 16 個（`0`〜`9`、`M`、上下（UV-K1 は左右）、`EXIT`、`*`、`F`）、サイドキー 2 個、PTT（→ [[キー操作]]） |
| ランプ | 赤＝送信中、緑＝受信中、青＝充電中（メーカーの説明）。RxJa では送信しないので、赤は点かないはずです（未確認） |
| その他 | 懐中電灯 |

## 中の部品

| 部品 | 型番 | 役目 |
|---|---|---|
| マイコン | PUYA **PY32F071**（Arm Cortex-M0+） | ファームを動かす |
| 無線チップ | Beken **BK4829** | ふつうの受信（と、純正ファームでの送信） |
| FM ラジオのチップ | Beken **BK1080** | FM 放送の受信 |
| SPI フラッシュ | PUYA **PY25Q16HB**（2 MB） | 設定・チャンネル・日本語データなどの保存 |
| 画面の制御チップ | **ST7565** 互換 | 128×64 の液晶の表示 |

- 無線チップは、ファームのソースでは古い型の名前「BK4819」で呼んでいるところが多いですが、実際に使っているのは BK4829 用の処理（`App/driver/bk4829.c`）です。
- 基板には「K1-V5.0」と印刷されています（分解写真より）。

## UV-K1(8) との違い

UV-K1(8) / UV-K1(8) L は、UV-K1 の外観違いです。前面が金属パネル（約 10 g 重い）で、電源つまみが太く、PTT の形も違います。サイドキーは UV-K1 と同じ並び（上から PTT、サイドキー 1、サイドキー 2）で、ファームも同じものを使います。

- 「UV-K1(8) は 8 MB のフラッシュを積んでいる」という説明を見かけますが、裏付けは見つかりませんでした。F4HWN も RxJa も、外付けフラッシュは全機種 2 MB（PY25Q16）として扱っています。
- 販売ページによって出力の表示が 5 W と 10 W に分かれていますが、ファームは同じです（RxJa では送信しないので関係ありません）。

## UV-K5 V3 との違い

RxJa は、UV-K1 と UV-K5 V3（UV-K5(8) V3 を含む）で**同じファーム**です。中の主な部品（PY32F071、BK4829）は同じで、違いは外側です。

| 項目 | UV-K1 | UV-K5 V3 |
|---|---|---|
| 大きさ・重さ | 98 × 59 × 33.8 mm、190 g | 115 × 60 × 37.5 mm、234 g（販売店の情報） |
| 矢印キー | 左右 | 上下 |
| 電池 | 1400 / 2500 mAh（K1 用） | K5 用（1600 / 2200 / 3500 mAh） |

- 矢印キーの向きの違いは、隠しメニューの「矢印操作（SetNav）」で合わせます（初期値は UV-K1 用の「左右 UV-K1」）。
- 電池の種類は「電池種類（BatTyp）」で、K5 用・K1 用のどちらも選べます。
- 旧型の UV-K5 / K5(8) の V1（マイコン DP32G030）と V2（マイコン PY32F030）とは中身が違い、RxJa は使えません（→ [[はじめに#自分の機種を見分ける]]）。
